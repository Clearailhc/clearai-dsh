# 数学案例：有限检验不是证明

## 问题
递归定义的整数序列前若干项都显示为素数，是否说明每一项都是素数？

## 命题
观测到的模式可以启发猜想，但有限计算本身不能证明每一项都为素数。

## 判据
将主张分成三类：(1) 已验证到明确下标的数值；(2) 一般模式的猜想；(3) 证明义务，例如归纳不变量、因式分解论证，或假设已核对的定理。

## 执行
使用精确整数算术生成各项，由独立实现的素性测试检查有限范围，并记录代码、种子、范围及可用的测试证书。随后尝试证明策略，但不能把数值表当作普遍真理的证据。

## 观察 / 评价
已检查的前缀可能没有反例，也可能强烈暗示某种模式。评价必须准确写成“已验证 n ≤ N”，而不是“对所有 n 成立”。证明失败不是否证；发现合数则是对全称命题的反例。

## 修订
将命题限定为已检查范围，明确表述为猜想，或在发现反例后修订它。若声称有证明，应展示每个引理及其假设，并寻求独立复核。

## 保留内容
保留精确递推式、有限表格、测试方法、证书、猜想措辞、证明草稿，以及区分计算与证明的状态标签。

## 局限
有限检验可能漏掉罕见失败，溢出或软件错误可能污染结果，启发式模式不具有演绎效力。证明必须覆盖所声明定义域并且论证有效。
