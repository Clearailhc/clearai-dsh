# AI4Sci 案例：把收敛性主张交给实验检验

## 问题与预期效果
一个可重复的数值实验，能否支持“重构在光滑临界点附近具有五阶精度”的主张？本案例展示：当实际实现和读数支持另一种阶数时，ClearAI 如何把一个吸引人的强主张收窄到证据真正覆盖的范围。

## 初始命题
选定的 WENO 实现应当在含光滑临界点的制造解上表现出五阶收敛。这个命题有意写得比下面的局部演示更强，并且允许被实验否定。

## 登记判据与执行题目
使用 `[0,1)` 上的 `u(x)=cos(2*pi*x)`，精确单元平均、周期索引、面值 `L-infinity` 误差和连续加密网格。固定方法、精度、边界处理和误差定义。执行命令为：

```bash
python3 lab/scripts/run_ai4sci_case.py
```

脚本和结果位于 [`lab/cases/ai4sci/`](../../lab/cases/ai4sci/)，记录函数、方法、网格、误差、观测阶数和运行元数据。

## 观测与评价

本次运行覆盖 16、32、64、128、256、512 个单元，观测阶数约为 3.98、4.00、4.00、4.00、4.00。在这一精确设置下，观测支持所实现四点重构的四阶收敛。

这不是“所有 WENO 实现都是四阶或五阶”的证据。本实验是受控的重构演示，没有覆盖非线性 WENO 权重、多维流动、激波、时间积分、边界闭合或所有临界点对齐情形。因此，第一次运行是一个局部观测，不是普遍精度结论。

## 修订后的有界结论

原命题修订为：**对于这个周期制造解、精确单元平均输入、四点重构、面值无穷范数误差和已测试网格范围，测得的收敛阶约为四阶。** 五阶 WENO 主张尚未被本次运行检验。更强结论需要明确的 WENO 变体、登记过的低阶基线、实现复核、独立重跑，并分别处理空间误差、时间误差、边界误差和舍入误差。

## 本次没有证明什么

本次运行没有证明一般定理、五阶精度、多维精度、激波行为、保正性、稳定性，也没有证明其他实现或其他问题类别的表现。数值证据仍受登记设置约束。
