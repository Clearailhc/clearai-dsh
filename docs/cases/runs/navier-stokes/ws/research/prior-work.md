# 与前人工作的关系

来源编号见 @research/sources.md。B 开头的是背景经典文献(模型已有知识,本次未联网复核);S 开头的是 2026 年检索摘要。「关系」一栏是我的分析,标明推理的地方都可以对照原文复查。

## 1. 前人工作逐项对照(12 项)

| # | 工作 | 它说了什么 | 与 2026 年结果的关系 |
|---|---|---|---|
| P1 | Leray 1934(B1) | 弱解全局存在;若光滑解在 T 爆破则 ‖u‖_∞ ≥ c(ν/(T−t))^{1/2};提出自相似爆破 u = (T−t)^{-1/2}U(x/√(T−t)) | 2026 年构造是 Leray 意义下光滑解在有限时刻失去光滑——说明对强迫问题 Leray 弱解在爆破后才是唯一的延拓框架;构造的速度增长必须满足 Leray 下界(见 @explore/scaling_out.txt 的量纲检查)。各向异性相似变量是 Leray 自相似思路的推广 |
| P2 | Caffarelli–Kohn–Nirenberg 1982(B2) | 适当弱解奇异集一维抛物 Hausdorff 测度为零 | CKN 对带适当正则外力也成立;2026 年构造的奇点是空间—时间中的孤立点(轴上一点、t=1),与 CKN 相容;一个细长涡核在奇点时刻收缩到一点而非一条线,恰好不违反维数上限(推断) |
| P3 | Nečas–Růžička–Šverák 1996;Tsai 1998(B3) | 排除 L³(及局部能量有限)的 Leray 型精确后向自相似爆破 | 这些定理针对**无外力**、**各向同性**的精确自相似解。2026 构造绕开它们靠两件事:(i) 各向异性(径向与轴向不同标度),(ii) 外力吸收余项。是「为什么需要外力/各向异性」的背景(推断) |
| P4 | Escauriaza–Seregin–Šverák 2003(B4) | L^∞_t L³_x 有界则不爆 | 2026 构造的 L³ 范数必发散;各向异性坍缩下 L³ 范数确实随 τ→0 增长(@explore/scaling_out.txt 计算出具体指数) |
| P5 | Tao 2016,平均化 NS(B5) | 把非线性换成保留能量恒等式的「平均化」版本后有限时间爆破:能量方法本身证不了正则性;用级联式「流体计算机」把能量一级级推到小尺度 | 2026 构造是「真」NS 加外力,而 Tao 是改非线性不加外力:两条不同的「放宽」。共同点是都利用级联/放大。Tao 的结果预言了「需要真正利用 NS 非线性结构」,外力在 2026 年起到了平均化在 2016 年起的作用——绕开障碍(推断)。二进级联玩具模型见 @explore/dyadic_out.txt |
| P6 | Buckmaster–Vicol 2019(B6) | 凸积分:有限能量弱解不唯一 | 方法论上相近:用振荡结构实现「应力」(Reynolds stress)。2026 构造中的「可容许应力锥」「振荡实现」「残余应力修正」(S2 目录)与凸积分术语同源(推断) |
| P7 | Albritton–Brué–Colombo 2022(B7) | 带外力时 Leray–Hopf 解不唯一;外力专门设计以产生不稳定自相似涡环 | 先例:「允许外力即可构造病态行为」。2026 年进一步得到**光滑解的有限时间爆破**,外力同样是设计出来的 |
| P8 | Elgindi 2021(B8) | C^{1,α} 速度的 3D Euler 有限时间爆破(无外力,有限正则) | 无粘爆破的里程碑之一;2026 年 Euler 强迫爆破(S3、S6)是「光滑数据 + 光滑外力」,换的是正则性代价为外力代价 |
| P9 | Chen–Hou 2022/2023(B9) | 带边界的 2D Boussinesq/3D 轴对称 Euler 光滑初值稳定近自相似爆破,计算机辅助证明 | 无外力、有边界、无粘;2026 构造无边界但有外力且有粘性。两者都用近自相似剖面 + 稳定性分析,但 Chen–Hou 靠区间算术验证剖面,2026 靠解析 + Lean |
| P10 | Hou 2021–2023 NS 潜在爆破数值(B10) | 轴对称 NS 数值上出现可能的爆破趋势 | 数值迹象,未成定理;2026 构造给出「带外力」下的严格版本,但无外力的 Hou 场景仍未证 |
| P11 | Wang–Lai–Gómez-Serrano–Buckmaster 等(DeepMind)2025(S23) | 机器学习 + 高精度 Gauss–Newton 发现 CCF/IPM/Boussinesq 的**不稳定**自相似奇点 | 路线是「找无外力的不稳定奇点再做计算机辅助证明」,被普遍视为通向无外力 NS 的路线之一;2026 年强迫构造是另一条路,不依赖不稳定剖面。Buckmaster 同时在两条路上 |
| P12 | Córdoba–Martínez-Zoroa 2024(S22) | 带紧支光滑源的 2D IPM 有限时间奇点;多尺度归纳:每层解作为背景流放大新加的振荡波包(「无穷级联」) | 2026 年两路工作(Buckmaster–Alpöge 与 OpenAI)都被描述为建立在 CMZ 之上(S7、S25);Buckmaster–Alpöge 明确是 CMZ 的推广(S6 题名);OpenAI 与 CMZ 的骨架关系说不清(见 @research/proof-outline.md §2) |

## 3. 判断「解析外力不可延伸」

- 推翻条件:找不到此类后续工作,或其结论相反。
- 读到的:F2(arXiv 2609.20803,作者据摘要为 Constantin、Ignatova、Vicol)摘要称在爆破前提下外力违反某正则条件、在奇点附近任何圆柱上不恒为零;S11 独立转述「三位数学家证明 OpenAI 的方法不能推广到完整问题」。两条来源方向一致。
- 结果:**支持**。范围:说的是「这一类(渐近轴对称)构造 + 解析外力」,不是「无外力 NS 一定正则」;作者名与精确条件来自检索摘要,未核原文。
