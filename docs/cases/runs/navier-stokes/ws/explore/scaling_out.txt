=== 1. NS 标度不变性的符号校验 ===
NS_λ[u_λ]_i - λ³·NS[u]_i(λx,λ²t) = [0, 0, 0]
div u_λ - λ²·(div u)(λx,λ²t)      = 0
结论:三分量差均为 0 且散度差为 0 → True (外力随之按 f_λ = λ³ f(λx, λ²t) 缩放)

=== 2. 各向异性坍缩的指数代数 ===
动能 ~ τ^(2*a + b - 2*c);Re ~ τ^(a - c);‖u‖_3^3 ~ τ^(2*a + b - 3*c);‖∇u‖_2^2 ~ τ^(b - 2*c)
代入 a + c = 1:
  (E)    4*a + b - 2 >= 0
  (Re)   2*a - 1 < 0   ⇔ a < 1/2
  (Ler)  1 - a >= 1/2 ⇔ a <= 1/2
  (Dis)  2*a + b - 1 > 0
  (An)   a > b > 0
  (E)+(An) 联立 ⇒ 2-4a < a ⇒ a ∈ Interval.open(2/5, oo)
  再与 (Re) a<1/2 联立 ⇒ 可行区间 2/5 < a < 1/2,b ∈ [max(2-4a, 1-2a, 0⁺), a)

=== 3. 具体例子(精确有理数) ===
例1(各向异性): a=9/20, b=3/10, c=11/20 | 动能指数=1/10, Re指数=-1/10, L3^3指数=-9/20, 耗散被积指数=-4/5
   条件满足: {'E': True, 'Re': True, 'Ler': True, 'Dis': True, 'ST': True, 'An': True, 'ESS': True} → 全部满足
例2(各向同性 a=b): a=9/20, b=9/20, c=11/20 | 动能指数=1/4, Re指数=-1/10, L3^3指数=-3/10, 耗散被积指数=-13/20
   条件满足: {'E': True, 'Re': True, 'Ler': True, 'Dis': True, 'ST': True, 'An': False, 'ESS': True} → 有不满足
例3(Leray 各向同性自相似): a=1/2, b=1/2, c=1/2 | 动能指数=1/2, Re指数=0, L3^3指数=0, 耗散被积指数=-1/2
   条件满足: {'E': True, 'Re': False, 'Ler': True, 'Dis': True, 'ST': True, 'An': False, 'ESS': False} → 有不满足
例4(R~τ^1/2 的粘性尺度涡核): a=1/2, b=1/4, c=1/2 | 动能指数=1/4, Re指数=0, L3^3指数=-1/4, 耗散被积指数=-3/4
   条件满足: {'E': True, 'Re': False, 'Ler': True, 'Dis': True, 'ST': True, 'An': True, 'ESS': True} → 有不满足

=== 4. 网格计数(步长 1/100,a,b ∈ (0,1),c = 1-a) ===
满足 (E)(Re)(Ler)(Dis)(ESS) 且 b<=a 的格点数 = 235(其中各向异性 b<a: 225,各向同性 b=a: 10)
可行格点上 a 的范围 = [2/5, 49/100]

=== 5. 读法 ===
- 量纲上存在指数使:动能有界、局部雷诺数发散(惯性压过粘性)、满足 Leray 下界、耗散积分有限、L3 范数发散(与 ESS 相容)。
- 但例2 显示各向同性 a=b 也满足这些纯量纲条件:量纲分析本身解释不了为什么需要各向异性;
  排除各向同性自相似爆破的 Nečas–Růžička–Šverák / Tsai 定理用的是方程结构(无外力)而不是量纲。
- 例3(Leray 自相似)Re 指数为 0:粘性与惯性同阶,是临界情形。
- 例4(R~τ^1/2、c=1/2)Re 指数为 0,同样是临界:若涡核宽度取粘性尺度 √(ντ),要让 Re→∞ 必须 c>1/2,
  此时翻转时间 R/U 短于 τ,不再满足简单的自相似时间关系——这正是需要外力与修正项吸收的地方(推断)。
