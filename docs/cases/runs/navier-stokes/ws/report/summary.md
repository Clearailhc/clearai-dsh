## 1. 结论

1. **被宣称解决的是「带外力的爆破」那一款,不是大家通常说的无外力问题。** 2026-09-08,OpenAI 发布 166 页论文《Finite Time Blowup for Navier–Stokes》和 Lean 4 形式化,宣称:对任意粘性 ν>0,存在一个**在空间和时间上都紧支的光滑外力**,使得**从静止出发**的 3D 不可压 NS 光滑解动能始终有界,却在有限时间内速度无界(S1、S2、S4)。
   - 对应 Clay 官方四款陈述中的 **C(R³ 上的破坏)**,OpenAI 还称给出了 **D(周期 T³ 上的破坏)**;Lean 仓库(据转述)同时形式化了 R³ 和 T³ 两条(S4)。
   - 按 Clay 规则,证明 A/B/C/D 任意一款都可以获奖,所以形式上它命中了一款可获奖陈述;但 OpenAI 明确说**不申领奖金**(S1、S15)。
2. **作者方**:OpenAI 内部的多智能体系统,据称约 1 万个 agent、约 88 小时(9-01 启动、9-05 得出),Lean 形式化另用 17 小时(S1)。另一方是 Buckmaster(NYU Courant)与 Alpöge(Anthropic),另有 Coiculescu 参与:他们在约早 12 小时的 9-07 公布了**带光滑外力的 IPM、2D Boussinesq、3D Euler** 爆破(**不是 NS**),同样附 Lean,并发表声明质疑信息流向和署名安排(S5、S6、S13)。
3. **发表与审稿**:截至 2026-10-02,只有公开预印本 + 作者自报的 Lean(自报 0 个 sorry、只用三条标准公理)。没有查到期刊接收或独立审稿通过的报道(S14、S17)。Clay 研究所 9-11 的说法是问题「apparently been settled(似乎已解决)」,评估程序「deliberately unhurried(刻意从缓)」,**没有正式认定,也没有授奖**(S9)。
4. **无外力的 Navier–Stokes 问题仍然开放**。专家称外力是「漏洞」(Silvestre:「带外力的表述与我们真正想解决的问题不同」,S11)。Constantin–Ignatova–Vicol 的后续工作(arXiv 2609.20803,S12)表明这类构造的外力不可能是实解析的,并且在奇点附近任何圆柱上都不恒为零。也就是说,这条路线不能靠「慢慢把外力关掉」走到无外力情形。
5. **证明思路(重建,中等可信)**:轴对称带旋转、**各向异性**(径向收缩快于轴向)的自相似坍缩涡核,相似变量为 τ=1−t、q、X=r²/2q、η=z/q^D(S18)。领头剖面的残差被当作「应力」,先验证它落在「可容许应力锥」里,再用高频振荡结构实现并逐级修正。最后剩下一个平坦余项,由一个穿过奇点时刻仍光滑的外力吸收(S2 目录项、S18、S19)。它的思想谱系通常追到 Córdoba–Martínez-Zoroa 2024 的强迫 IPM 爆破(S7、S22、S25)。

## 4. 与前人工作的关系(摘要,详见 @research/prior-work.md)

- **Leray 1934**:2026 构造必须满足 Leray 下界 ‖u‖∞ ≳ (ν/τ)^{1/2},各向异性相似变量可以看成 Leray 自相似设想的推广。
- **CKN 1982**:奇点是时空中的孤立点,与「一维抛物 Hausdorff 测度为零」相容。
- **NRS 1996 / Tsai 1998**:它们排除的是无外力、各向同性的精确自相似爆破。2026 构造靠两点绕开:一是各向异性,二是用外力吸收余项。
- **Tao 2016**:Tao 是改非线性、不加外力;2026 是保留真实非线性、加外力。两条路都绕开了「仅靠能量方法」的障碍。
- **Buckmaster–Vicol 2019 / ABC 2022**:2026 构造里「应力 + 振荡实现」与凸积分术语同源;ABC 是「设计外力制造病态」的直接先例。
- **Elgindi 2021、Chen–Hou 2022、DeepMind 2025**:都是无外力的 Euler / Boussinesq 爆破路线,代价分别是有限正则性、带边界、只有数值;2026 换成了「光滑 + 无边界 + 有外力」。
- **CMZ 2024**:被普遍视为 2026 年两路工作的共同源头。

## 5. 动手探索的发现(可重跑)

- `python3 explore/scaling.py`:(1) 标度不变性三分量残差差值都是 [0,0,0];(2) 在自相似时间 a+c=1 的约束下,可行区间是 2/5<a<1/2;(3) 步长 1/100 的网格上有 235 个可行点,其中各向异性的 225 个;(4) 但各向同性同样可行,所以量纲本身不要求各向异性。另外,若涡核宽度取粘性尺度 √(ντ),Re 指数为 0(临界),要让 Re 发散就必须让翻转时间短于 τ。这是外力与修正项需要吸收的「不自洽」(推断)。
- `python3 explore/dyadic.py`:在二进模型里,「级联 vs 粘性」的胜负取决于耗散指数:α<1/3 时出现收敛的爆破时刻(≈1.764 和 ≈1.797),α≥1/2 时与截断无关、保持有界,和 Cheskidov 2008 的定理一致。这说明级联机制本身足以在有粘性时爆破,前提是粘性在小尺度上不够强。真 NS 的「有效 α」在哪里,正是问题的核心。

## 7. 接下来值得做的问题(按推荐顺序)

1. **独立编译并审计 Lean 仓库的「陈述忠实度」**:逐条对照 Fefferman 原文 C/D 的初值类、外力衰减条件、「光滑」与「有限能量」的定义。理由:这是把「宣称」变成「事实」最便宜、最可机械化的一步。目前只有作者自报的 0 sorry,而所有争议都落在形式化陈述是否被「量身改写」(S21)。**首推。**
2. **外力能「多小」或「多自然」?** 把 Constantin–Ignatova–Vicol 的解析障碍推向定量版本:Gevrey 类外力是否可行?外力的某个临界范数下界是多少?理由:这是连接「强迫爆破」与「无外力问题」的唯一定量桥梁,能说清楚这个漏洞到底有多大(S12)。
3. **无外力的不稳定自相似剖面 + 计算机辅助证明**:沿 DeepMind 2025 与 Chen–Hou 的路线,把 Boussinesq/IPM 的不稳定剖面推进到轴对称 NS,并用区间算术证明。理由:这是目前唯一被认真看好的、通向 A/B 反方向(无外力爆破)的路线;强迫构造给出的各向异性涡核几何,可以作为数值搜索的初猜(S23、B9、B10)。
4. **各向异性自相似 Liouville 定理**:NRS/Tsai 排除了各向同性自相似爆破;能否对 OpenAI 型「径向 q^{1/2}、轴向 q^D」的各向异性剖面,在**无外力**时也证明不存在?理由:如果能证明不存在,就和障碍定理一起把这条路线彻底关上;如果证不出,失败之处可能正好指出无外力爆破的候选。探索 §5 已表明量纲本身不排除它们。
5. **二进 / 壳模型里的「外力漏洞」类比**:在 Katz–Pavlović 或 Tao 平均化模型里系统研究「光滑外力能否把 α≥1/2 的正则模型推爆」,以及外力需要多大的范数。理由:便宜、可数值化,能先在玩具层面检验「外力等价于降低有效耗散」这一直觉(可以直接扩展 @explore/dyadic.py)。
6. **周期情形 D 的独立核对**:确认 T³ 版本的外力与初值确实是光滑周期的,而不只是 R³ 构造的截断复制。理由:Lean 仓库据称两条都有,但公开讨论几乎只谈 R³(S4)。
7. **AI 证明的可审稿规范**:按 Tao 的建议(S16)公开失败尝试与中间产物,让人类可以消化证明的「洞见」。理由:这是社区层面的问题,不是数学问题,但它决定这类结果多快能被确认。
