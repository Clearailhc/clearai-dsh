# ClearAI 定位

## 它是什么

ClearAI 是一个**原生于 DSH、基于认识论的本体研究平台**：研究的沉淀形态是**本体**——项目自己的领域语言（词汇）、经循环确立的知识条目、以及它们的图。认识论循环是本体的**生产工艺**：提出假设，检查或验证，记录观测，评估结果；每个词条带依据接纳，每条知识凭证据确立，被推翻的留作负知识。

一句话分界：别的知识图谱靠抽取与断言堆边；这里的**每一条边都要通过循环挣得**。真值方向永远不变——世界 → 证据 → 事实 → 长成本体——所以**本体不裁决任何事，它只收留被裁决过的东西**。

ClearAI 不是自主真理机器、通用聊天包装层，也不宣称递归自我改进（RSI）。它帮助人更好地推理，而不取代人的判断。

## 面向人群

ClearAI 面向处理以下问题、且具有好奇心和技术思维的人：来源相互冲突、证据不完整，或尚未明确求解路径的问题。典型用户包括研究人员、工程师、分析师、构建者和独立调查者。

## 差异化

多数 AI 产品优化的是流畅回答、任务完成或对话历史。ClearAI 围绕**知识的状态**组织工作：哪些是待检验假设，哪些已经核查，观察到了什么，仍有哪些不确定性，以及结论为何值得信任。DSH 提供原生的工作台能力：持久工作区、明确的执行模式、受治理的计划、证据记录和可逆历史。

## 四项承诺

1. **让不确定性显性化。** 区分问题、假设、观测、评估、证据和事实。
2. **让探究可追溯。** 保持从提示到工作再到结论的过程可检查、可恢复。
3. **让结论有边界。** 保留置信度、来源、未解决的替代解释，以及结论成立的条件。
4. **让知识有形态。** 已确立的结论沉淀为本体条目（词汇 + 内容 + 图），下一轮按概念取用，而不是重读散文。

## 边界

- ClearAI 支持探究，但不保证真相，也不替用户做高风险决策。
- 它可以搜索、分析、测试和整理证据，但不能把缺失的证据变成确定性。
- 自动化受工具、工作区权限、来源质量和明确的验证流程约束。
- 判断、批准、解释和后果性行动仍由用户负责。
- ClearAI 不宣称 RSI、意识、独立主体性或不受约束的自主性。

## 术语

- **认识论工作台（Epistemic harness）：** 组织探究、记录状态，并让主张持续关联证据的周边系统。
- **认识论循环（Epistemic Loop）：** 假设、验证、观测、评估、证据和有边界结论组成的可重复循环。
- **Harness：** DSH 原生的模型与工作区执行、治理层；这不是对模型本身的描述。
- **证据（Evidence）：** 支持某项主张的记录，包含来源和局限。
- **事实（Fact）：** 在当前工作区中、依据已记录证据并在既定范围内接受的主张；不是永恒保证。事实是本体的**内容单位**——以本体词汇写成断言，在升格那一刻进架。
- **本体（Ontology）：** 项目知识库的语言与内容的整体：词汇（约定）、已确立条目（经验）与它们的图。产品语境下默认指领域本体；过程本体是插件内部的流转结构，不在此列。
- **本体货架（Ontology shelf）：** 本体已确立内容的货架视图：每条带边界与支持等级；未结构化的旧条目照旧在架，标「未结构化」。
- **有边界结论（Bounded conclusion）：** 明确写出置信度、条件、替代解释和剩余不确定性的结论。
