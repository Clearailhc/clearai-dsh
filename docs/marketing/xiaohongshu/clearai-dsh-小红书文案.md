# clearai-dsh：在 DeepSeek Harness 上构建可信本体

## 小红书发布文案

### 标题建议

**AI 的答案为什么不敢直接用？我们在 DeepSeek Harness 上做了一条可信本体构建路径**

### 正文

很多人用 AI 做研究、调研、业务分析，都会遇到同一个问题：

答案看起来没问题，证据却找不到。

聊天记录里有结论，向量库里有文档，但你很难回答：

- 这条结论从哪里来？
- 经过什么验证？
- 和另一条结论冲突时，谁应该被保留？
- 下一轮研究能不能直接接着用？

ClearAI 做的事情很直接：

**在 DeepSeek Harness 上，把可信本体的构建路径走通。**

它有两个核心部分：

### 1. 本体：研究最后留下的知识结构

一个项目的本体包括：

- 概念：项目里有哪些重要的东西
- 谓词：这些东西之间有什么关系
- 实例：具体的对象、样本、订单、设备或实验对象
- 断言：经过验证的具体关系
- 本体图与实体图：领域结构，以及已经确认的事实

本体不是一张关系图。

每个概念和谓词都有来源；每条事实都有证据和适用边界；废止的内容保留记录，不直接删除。

### 2. 认识论循环：本体建立的验证过程

认识论循环负责处理一个问题：

**这条知识凭什么成立？**

ClearAI 把它落成了七个阶段：

`界定 → 提出假设 → 规划 → 观测 → 验证 → 评估 → 记录并行动`

它不是一张流程图，而是写进工具和账本里的约束：

- 结果出来之前，先登记判据
- 计划推进必须交付证据
- 高等级结论需要独立评估
- 被推翻的命题保留在记录里
- 模型不能直接把某一步改成“已完成”
- 知识任务不用你提醒：目标带着登记过的假设，系统自己进入知识模式（预检已知、读出缺口、结案前拦住没有形态的核心结论）

最终结果是：

**认识论负责检查过程，本体负责保存结果。**

## 它和普通知识图谱有什么不同？

普通知识图谱通常从文档里抽取实体和关系，然后把边画出来。

ClearAI 里的关系要经过：

`词汇登记 → 假设提出 → 判据登记 → 证据交付 → 验证评估 → 事实升格`

关系经过验证后才进入已确认的知识结构。

如果发生冲突，系统不会偷偷选一边：

同一个主体、同一个单值谓词、两个不同取值，会显示为一对冲突。两边都保留，撤回或维持由人决定。

这比自动“清洗”更可靠。因为系统不知道哪条测量出了问题，也不知道两个结果是不是来自不同条件。

## 界面里能看到什么？

本体面板里有五层内容：

1. **图带**：本体图 / 实体图一键切换，节点带类型、边带名字
2. **知识 Inspector**：点节点或边，右侧给出释义、依据、状态、子概念、相关谓词、登记与修订史
3. **本体货架**：已确认事实、证据、边界、支持等级
4. **断言芯片**：事实使用了哪些概念和谓词
5. **词汇维护区**：概念、谓词、依据、版本、废止原因

点击图中的概念节点，可以直接过滤下面的货架（“按此筛选”是详情里的显式动作）。

图不是装饰，是导航入口。

图上的内容全部来自同一份账本：同一场会话、同一份事件流，永远折出同一张图。

## 适合哪些事情？

### 科研探索

- 管理假设和推翻条件
- 保存每一轮实验与证据
- 区分暂时结论和已确认事实
- 保留失败路线和负知识
- 按概念检索以前的研究结果

### 业务建模

- 把业务概念登记成稳定词汇
- 用谓词表达业务关系
- 用单值约束发现数据冲突
- 让领域模型与验证记录关联起来

### 技术调研和分析

- 结论带出处
- 不同来源的矛盾自动出现
- 研究结果可以继续累积
- 下一轮按概念继续，而不是重新阅读全部材料

## 设计上最重要的几条原则

### 没有第二本账

账本里的事件是唯一事实来源。面板展示的是事件折叠出的投影，不自己保存一份状态。

### 词汇不是事实

“铸锭”“订单”“样本”这些概念是约定。用这些词写下、并经过验证的断言，才是经验内容。

### 冲突不被隐藏

系统负责发现和展示冲突，不替人裁决。

### 历史不被删除

修订留版本，废止留原因，被推翻的事实继续存在。审计需要完整历史。

## 现在的项目状态

- 版本：0.2.1
- DSH 原生插件
- 29 个意图工具
- 15 套测试全绿 · 1618 条断言
- 本体、断言、冲突、图投影、知识 Inspector 已经落地
- 图由 React Flow 渲染：拖节点、滚轮缩放、全景、全屏图谱工作区
- 支持中文和英文界面

安装：

```bash
npx clearai-dsh install
```

安装后重启 `dsh web`。**新建会话，点顶部的模式名，在预设列表里切成 `ClearAI`**——默认的“标准模式”不会挂载认识论循环。
