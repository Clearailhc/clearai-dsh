# 收率优化报告：x,y∈[0,1]，杂质 ≤ 0.115

## 结论

- 推荐配方：**x = 0.4517，y = 0.4485**（两个输入均为归一化 0–1 坐标，见 `initial.json` 的 `bounds`）。
- 该点有 **4 次 full 原始读数**：94.7228 / 95.0484 / 95.1643 / 95.2801 %，均值 **95.05**（se 0.12）；四次单读数均 ≥ 初始 9 点最好的 94.693（@ (0.5,0.5)）。
- 同一批 full 读数的杂质：0.0819 / 0.0834 / 0.0834 / 0.0840，全部 ≤ 0.115（余量约 0.031）。
- 二次响应面拟合给出的理论极值点在 (0.4528, 0.4476)，预测 95.05——与实测点相差 <0.003 个坐标单位，等价。
- **改善幅度要打折看**：均值 95.05 比初始最佳 94.693 高 +0.36；但按脚本口径（`variance = max(残差方差, 0.18²)`），16 点模型在该点的 95% 预测区间是 **[94.68, 95.43]**（σ_pred 0.19；事前 10 点模型为 [94.55, 95.37]）。区间下界 94.68 **略低于**初始最佳 94.693，所以"最优点优于初始最佳"在单次读数层面成立（4 次都 ≥ 94.693），但在 95% 水平上**不能宣称显著提高**。若同坐标 4 次重复的单调上升是仪器正漂移（见局限第 6 条），改善幅度还应下调到约 **+0.15~+0.20**。

## 方法

1. 用 `method/response_surface.py` 对 `initial.json` 的 9 个 full 点拟合：9 点 3×3 设计下加性 CV 0.0923、交互 0.1142，脚本按「简单模型在噪声内优先」选 **additive**。但注意 9 点拟合残差 sd 仅 0.062，远低于标称 0.18，这个 CV 偏乐观（见「局限」第 5 条），**最终结论不以 9 点 CV 为依据**，而是用全部 16 点与去重 13 点重算。
2. 用 5 次 quick（成本 1/次）核对形状：4 个轴点 (0.20,0.45)/(0.70,0.45)/(0.45,0.20)/(0.45,0.70)，加 1 个重复核对点 (0.5,0.5)。它们相对最终 full 二次面的残差为 +0.49 / +0.03 / −0.71 / +0.23 / +0.24（均值 +0.06，sd 0.46，quick 标称 sd 0.45），无明显系统偏移，但噪声约为 full 的 2.5 倍，故 **quick 只用于形状核对，未混入拟合**。
3. 用 full（成本 3/次）在预测最优附近布点：1 点在 (0.45,0.45)、4 次重复在 (0.4517,0.4485)，另加 2 个中间半径点 (0.25,0.60)、(0.60,0.25) 作覆盖检查。
4. 每次新增读数后用 `response_surface.py --append` 重拟合并另存 `lab/input-final.json`（原 `initial.json` 未改动）。

## 模型参数（全部 full 点，n = 16，物理坐标）

收率（单位 %）：

```
yield(x,y) = 84.883 + 24.074·x + 21.081·y − 26.583·x² − 23.550·y²
```

- 残差标准差 0.170，最大残差 0.33；脚本给出的加性 LOO CV 0.1678。
- 极值点 x₀ = 24.074/(2·26.583) = 0.4528，y₀ = 21.081/(2·23.550) = 0.4476，预测极值 95.05。
- 加性 vs 交互：脚本缩放坐标下交互系数 −0.027，折合物理坐标 **−0.108**；交互模型 LOO CV 0.1805 > 加性 0.1678。**去重 13 个不同坐标**后：加性 CV 0.1711、交互 0.1932，加性仍更好；重复点使交互系数标准误由 ~0.06 增至 ~0.14（缩放坐标），这是重复点集中在最优区的代价。

杂质（单位：分数 0–1，脚本按 CV 选加性）：

```
imp(x,y) = 0.05539 − 0.00045·x + 0.04690·y + 0.03120·x² + 0.00337·y²
```

- 残差 RMSE 0.00083，最大残差 0.0014；16 点拟合在推荐点预测 0.0833，预测上界 **0.1041** < 0.115。
- 杂质随 x、y 上升；约束只在 (0.9,0.9) 附近才会被触碰（实测 0.1247 > 0.115），最优区不受约束。

## 仪表口径

- 仪器：`original`（未更换）。`calibrate`（成本 2，@0.5,0.5）返回 `offset = 0`、`unit = "normalized x"`，即输入按 0–1 归一化、无附加零点偏移；本次全程使用同一仪器，未套用其他仪器的修正。**校准只在开始时做过一次**，结尾未再核对，见局限第 6 条。
- 读数口径：`value` 为收率，单位 **%**；`impurity` 为杂质，单位 **分数**（0–1），上限 0.115 即 11.5%。质量分数/体积分数未在元数据中区分，按 `initial.json` 的 `units` 原样记录。
- 模式差异：`full` 标称噪声 sd = 0.18（% 点），`quick` 标称 sd = 0.45；两者同一仪器、无系统偏移。`initial.json` 记录的 9 个点与后续点都是 full。
- 成本与花费：quick 1 / calibrate 2 / full 3；共花 **28 / 30**，余 2 单位（不足再一次 full，故未再花）。

## 验证与局限

- **已验证（单读数层面）**：推荐点 4 次独立 full 读数，最差一次 94.72，最好的 95.28；4 次均 ≥ 初始最佳 94.693；杂质 4 次均 ≤ 0.115。模型层的点估计用 4 次**均值 95.05**，不用最大值——脚本 `best_measured` 取的是单次最大值（95.28，比均值高 +0.23），那是选择偏差，不作为结论口径。
- **模型充分性**：加性二次面在 16 个 full 点上残差 sd 0.17 ≈ 标称噪声；两个中间半径点 (0.25,0.60)、(0.60,0.25) 在**并入拟合前**由 10 点模型预测的偏差为 +0.115 / +0.368（在噪声内）；并入后它们的残差（+0.06 / +0.28）属事后残差，不算独立验证。
- **改善幅度**：见「结论」——+0.36 与 95% 预测区间宽度同量级，且区间下界低于初始最佳，不能宣称显著提高。
- **局限**：
  1. 只在观测盒 [0.1,0.9]² 内有数据支持；脚本明确「观测包围盒不是插值支撑」，盒外（如 x 或 y 接近 0/1）不做外推。
  2. 峰很平：偏离最优点 0.1 个坐标单位，收率只降约 0.26；单次 full 噪声 0.18 无法分辨 <0.2 的差异。
  3. 3×3 初始网格间距 0.4，理论上可能漏掉尺度小于 0.2 的窄峰；5 次 quick（噪声 0.45）未发现 >1% 的异常高点，但不能排除 <1% 的局部凸起。
  4. 单仪器、无第二仪器交叉校验；杂质口径（分数）按元数据采用。
  5. **两批噪声不一致**：初始 9 点对二次面的残差 sd 仅 0.062（4 自由度，若真噪声 0.18，出现这么小残差的概率约 2%），而后 7 个 full 点残差 sd ≈ 0.18–0.20。因此 9 点阶段的 CV 0.092 偏乐观；把 16 点与去重 13 点一起看，加性/交互的结论不变，但"模型误差"这一项应按 0.17 估。
  6. **顺序效应/漂移未排除**：同坐标 4 次重复按时间单调上升 94.72 → 95.05 → 95.16 → 95.28（极差 0.56）。用初始 9 点模型预测后 7 点，残差 +0.18 / −0.17 / +0.15 / +0.16 / +0.42 / +0.27 / +0.39，均值 +0.20，且最后两点偏高。这可能来自局部曲率（峰比二次面更尖）或仪器随时间的小幅正漂移；剩余预算 2 不足以再做 full（成本 3），无法区分。若属漂移，真实改善应从 +0.36 降到约 +0.15~+0.20；若属局部曲率，则最优点还会略高。两种情形都不改变最优位置（0.45 附近）与杂质可行性。
