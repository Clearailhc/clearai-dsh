## 数据与真实性边界

`research-events.js` 投影版本为 3。只读已提交的 ClearAI 工具结果或带来源验证的内核事实记录。按语义载荷去除工具与事实通道的重复；来源序号、修订、时间、对象和证据入口保留。不同假设和不同裁决各有记录；结构明确标为定义，实体登记保持待核验。无关工具活动保持投影引用不变。

本体文件变化以已提交的 `workspace/synced` 记录为输入，排除读取错误、删除项、未通过文件 schema 的数据。它表示记录了定义或断言，不代表独立验证已通过。旧会话只能重放实际存在的提交来源。

UI 缓存没有写入内核、目标管理、任务控制或模型消息的出口。刷新重放不调用模型。行内对象是静态历史文字，没有定位按钮或选中副作用；研究和本体通过原生独立页签阅读。跨页签定位不属于本版范围，不作为待补宿主能力或发布门槛。可信性异常与取消后的推进仍由原有内核约束，展示层不能覆盖它们。

## 复现隔离预览

先执行 `npm run build`，再运行：

```bash
node tools/research-preview/start.mjs --host-node-modules /path/to/official-dsh/node_modules --port 3091
```

终端会显示实际 DSH 页面地址。打开示例工作区中的会话，使用回放按钮。独立的预览 profile 使用官方 bundle 与公开插件接口，不复制宿主页面、不修改引擎。当前截图脚本使用本机 Chromium 和临时 FFmpeg 路径；录屏不是跨浏览器或读屏器验收。

视觉升级前的预览曾重现初始空会话切换时的 `uiConversation.binding: unknown session` 异常，原始检查和截图保留在 `before-visual-upgrade/`。已修复插件在旧 Session 绑定释放前同步增删视图的时序：将席位同步合并至下一事件循环，卸载时撤销待执行同步。最终真实浏览器在等待页面就绪后连续切换十轮，均恢复九条记录，页面错误和控制台错误均为零；键盘展开/收起通过。回放的点击至可见耗时只是小样本交互测量，不是正常负载下事件抵达至绘制的 P95 验收。

最终发行包的构建、自检与干净安装检查通过；生成件由仓库构建流程重建。本地包为 `dist/clearai-dsh-0.5.9.tgz`，哈希、预览来源对应关系及未通过项见 [acceptance.json](acceptance.json)。[最终短录屏](preview.webm)、[中文浅色](dsh-zh-light-1440.png)、[英文深色](dsh-en-dark-1440.png)、[独立本体页签](dsh-ontology-1440.png) 和 [保留日志](logs/) 可供审阅。

## 整体视觉与交互修复

对话采用细线时间轴、类别线性图标、轻量文字状态和紧凑对象入口，默认收起来源信息；示例标签缩为 DEMO，保留明确示例说明。研究与本体面板统一字重、留白、边框、标题层级和响应式布局，沿用宿主主题。历史对象入口使用原始记录名称，不从最新投影改写历史标签。

普通意图发送现在区分正在发送、已确认发送、失败；异步拒绝不再被吞掉，发送前及返回时核对当前会话/目标。新增延迟发送、失败与过期操作回归用例。已移除跨页签对象交互与补救提示，不修改宿主源码、不使用 DOM 操作绕过。

快速重叠切换检查曾在点击新会话后仅 100ms 切回，捕获宿主 `Session reference is released` 控制台错误；记录随后恢复完整。此尝试保留在 `logs/clearai-ui-capture-retry.log`，不将最终等待就绪后的通过结果解释为该宿主竞态已修复。另有首次预览启动等待超时及主题页面加载超时，原始日志均保留。
