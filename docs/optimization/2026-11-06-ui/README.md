# 研究面板、本体面板与图谱视觉升级

2026-11-06。基于 ClearAI 0.5.7；DSH 0.2.2-rc.1。保留本次会话的 DSH 兼容性修复，未升级版本、未发布。

## 设计与交互

- 统一系统无衬线字体、标题层级、留白和细边框。研究面板在宽屏采用问题主栏与下一步侧栏，窄屏回到单列。本体面板先展示知识地图，再展示结论及依据。
- 概念用空心菱形、实体用实心圆点，数值用较轻的底色；节点保留可读名称、类型与完整名称提示。根概念稍加强调，颜色用于焦点和状态。
- 本体层级采用分列布局和圆角折线，实体关系采用平滑曲线；边带方向箭头和较大的点击区域。选中节点突出相关连接，密集图减少常驻边标签。
- 图谱提供搜索、目录列表、邻域、聚焦所选、概览和全屏。查看详情不会重置用户视口；跨层切换清理旧定位任务。搜索可展开折叠祖先并定位屏外对象。
- 默认缩放下限为 80%，优先保证文字可读，因此大图可能超出画布；用户可平移、搜索，或主动选择概览。不会截断数据来减少节点数量。
- 窄屏全屏详情使用底部抽屉，保留画布宽度。核心入口使用原生按钮，提供键盘焦点、全屏焦点约束和 Escape 退出。
- 本体图明确标注“概念与关系定义，不代表事实已验证”，与实体断言的核验状态分开呈现。

## 验证

- 将最终构建重新安装到真实 DSH 测试配置后，完整 `npm test` 通过，包括宿主 38 项、客户端 180 项及其余内核/领域/不变量等套件。见 [完整日志](tests.log)。
- `npm run verify`：45 项通过。见 [打包日志](package.log)。
- `node tools/browser-panels-check.mjs`：面板渲染、375/768px 研究布局无页面溢出、搜索与键盘选择、邻域、图层切换后的节点可见性、列表、全屏与 Escape、窄屏详情、深色渲染、查看详情时视口保持、50 节点不截断及屏外节点搜索定位均通过。见 [浏览器测量](checks.json)。

浏览器复现需要先运行 `npm run build`，安装系统 Chromium，允许本地监听和子进程。可用 `CHROME_PATH` 指定浏览器路径；截图输出至 `.tmp-audit/design/`。
