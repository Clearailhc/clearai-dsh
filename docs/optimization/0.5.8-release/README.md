## Model-loop repair follow-up

The malformed-argument failure now has a lossless recovery path: ClearAI calls that end in a native `MALFORMED_RESPONSE` retain their original argument bytes and reach an explicit pre-execution denial. No JSON repair or tool action is inferred. Both thrown errors and native terminal failure chunks are covered; cancellation and unrelated transport failures remain errors. Installed DSH block assembly and kernel no-dispatch regressions pass. The strict suite now has 704 kernel assertions.

A new fast run passed in 70 seconds with one evaluator and no parent polling. Cancellation and disconnect checks passed. The first recovery verifier was found to accept a replacement goal caused by its own follow-up message; that sample is excluded. Recovery now supports resuming without adding a new user task and requires the original goal ID.

A separate isolation probe exposed a session-title request that outlived the main agent and lost its usage during shutdown. The test driver now drains all model accounting before exit and rejects completed runs with pending or unknown usage. The unresolved request retains its full $0.80 reservation; all paid batches are paused pending an explicit decision on this accounting exception. Current aggregate bound, including that reservation: $2.5467608. No ledger entry was cleared or treated as free. See [follow-up numeric results](recovery-results.json).
