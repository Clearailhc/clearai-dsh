# 0.5.8 acceptance — in progress

Release is blocked until every required gate has evidence for the final candidate. No tag has been created and no npm publication has been performed.

Target: DSH 0.2.2-rc.1, Node 22/24 Linux and Node 24 Windows. Real-model tests use official DeepSeek `deepseek-flash`, requested reasoning effort `medium` for both main agent and evaluator. The provider documents that `medium` maps to effective `high`: https://api-docs.deepseek.com/guides/thinking_mode/ .

Peak USD prices checked 2026-11-06: cache-miss input $0.30/M, cache-hit input $0.006/M, output $1.20/M. Source: https://api-docs.deepseek.com/quick_start/pricing/ . Budget checks deliberately count cached tokens at the higher input rate and reserve $0.80 per in-flight request. Test ceiling is $5 including retries and all its agents; shared campaign ceiling is $30. Missing usage stops the campaign. These are conservative cost upper bounds, not provider invoices. No paid provider search/fetch tools are configured.

Preliminary failures are retained: first fast run was rejected before any model request because the host catalog did not declare the model's reasoning capability. The next fast run exposed a missing JSON Schema type on criterion results, preventing evaluator dispatch; it is a functional failure, not a passing sample. One reinstall also detected a stale same-name tarball in the package-manager cache; candidate filenames now include their content digest.

Pre-change red-team evidence remains in [2026-11-06-redteam](../2026-11-06-redteam/). Historical model results remain in [0.5.2 validation status](../0.5.2-plan/pr23-validation-status.zh-CN.md) and the [bare-model comparison](../../cases/bare-model-ab.md). ## Current gate results

- Strict Linux Node 24 suites passed without skipping installed host or client checks: kernel 701, host 38, client 180, plus domain, ontology, state-machine and other suites. Dedicated integrity/copy tests: 6; monetary budget tests: 5.
- Reproducible package: 45 checks passed. Workspace residue check passed. Native DSH session append/cold replay contract passed. Real 0.5.7 → 0.5.8 install/upgrade/uninstall/reinstall passed.
- Production-component browser checks passed in Chinese and English, including 200 nodes, self/reciprocal edges, keyboard edge selection and 30 projection updates with zero graph node/edge removals. Real DSH Explore/Ontology pages loaded at 1440/768/375px without horizontal overflow or runtime errors; `native-*.png` records the synthetic arithmetic acceptance session.
- Same-machine graph performance: an initial 3-sample 50-node result exceeded the 20% line; retained in `graph-performance-initial.json`. A subsequent 5-sample run after other browser workloads finished measured 14.1% / 17.7% first-render increases for 50 / 200 nodes, and 12.1% / 5.9% update increases. This is limited synthetic evidence, not a claim of faster rendering.
- Equal-file copy benchmark: 400 × 64KiB, five runs. Sync baseline median 57.6ms; async candidate 252.6ms. Event-loop maximum-delay median fell from 57.9ms to 2.4ms. Responsiveness improved while copy throughput worsened; no end-to-end efficiency claim follows.
- Fast-05 and the 305-second wait test passed, with one evaluator and zero parent model requests while waiting. Later fast and cancellation attempts failed on malformed `Conclude` JSON generated by the model. Cancellation, disconnect, process recovery and six paired smoke remain incomplete; these functional failures block release. See [numeric results and total cost bounds](real-model-results.json).
- Linux Node 22 and 24 passed remote CI run 42159315961. Windows Node 24 exposed a test race: a fixed 50ms sleep was shorter than the new asynchronous snapshot copy. The assertion now waits for evaluator dispatch with a bounded deadline; the next Windows run passed all suites, then exposed `spawnSync npm.cmd EINVAL` in the older package verifier. That verifier now invokes the npm JavaScript entry through Node on Windows; the next Windows run passed package validation. Native-contract imports then exposed Windows drive letters being treated as URL schemes; explicit file URLs now cover both runtime and projection imports. The final Windows rerun remains required.

Raw model logs are retained in the local test environment. Automatic approval rejected copying full conversation payloads into the repository because they could contain sensitive data; this repository contains only an allowlisted numeric summary and content hashes. No successful sample replaces a failed attempt.
