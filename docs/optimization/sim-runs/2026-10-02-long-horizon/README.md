# 五个长程任务实测(2026-10-02,基于 0.4.0 + retests 修复)

计划:[ClearAI 五个长程测试任务](https://claude.ai/code/artifact/1846903c-77c0-4eed-9331-20529ba296d2)。题目与答案在 `tools/sim/long-horizon/`。
扮演模型、评估者、裸模型与盲评的子代理一律 Sonnet 5.5(`claude-sonnet-5-5`),思考强度中。每个任务都带裸模型对照(同一份任务书,不装 ClearAI)。
盲评子代理只看最终答复与交付文件,对照答案逐条打分,另记「错而自信」条数。

## 一句话结论

正确性上 ClearAI 与裸模型基本打平;唯一拉开差距的是反应工艺(2.5 对 0.5),而那一分来自独立评估者顺手指出的温度漂移。
代价是平均约 2.4 倍耗时。根本原因是:**验证等级由模型自己标,模型一律标成可以自判的 L1/L2**,于是中途独立评估、事实升格、跨会话复用、retests、L4 人放行这几件 ClearAI 的核心机制在 9 次运行里一次都没有真正触发。

## 机制在实测中的表现

**起了作用**
- Conclude 的独立评估每次都派了,全部按时落定。反应工艺那次评估者在备注里点出 T_ref 比设定低 8 °C,模型据此补了更正,成绩从 OFAT 档拉到 2.5。
- 目标做不到时如实 abandoned(装箱),附上界证明。
- 每步「观测 + 判据对照」让答复里的状态标注更整齐;但裸模型在同一任务书下也标得同样好。

**从未触发或被绕过**
1. **等级自定(F2/F7)**:9 次运行的所有步骤都是 L1 或 L2,0 次 L3、0 次 L4。L0–L2 允许模型自判,所以中途没有一次独立评估;升格门槛是 L3,所以 **0 条事实**。会话二、三读不到会话一的事实,「定义已变」、retests、fact/reviewed 全部空转,这次的 retests 修复没有机会被实测验证。
2. **L4 放行门被绕过(F5)**:中试是一次性外部装置,应走 L4 等人放行。两组 ClearAI 都直接用命令跑了中试,步骤标 L1;设成「先不放行」的那组也照跑。内核看不到这条命令。
3. **评估者不能复跑(F6)**:评估者工具白名单只有 read/glob/grep,「L3 = 可重跑的新证据」在评估时从不重跑,只核对文件彼此是否一致。
4. **判断写成结论(F1)**:数学任务里模型把假设立成「1 假」「6 未知」,然后都「支持」。账上 7 条全是支持,DSH 上看不到一条「已推翻」。
5. **放弃不经评估(F3)**:`Conclude(abandoned)` 不派评估者;本体声明里这条边的守卫写着 independent_verdict_written,代码没执行,声明与实现不一致。
6. **产物路径先写死(F8)**:工厂和调研两次都因为立计划时随手写的本体文件名与实际不符,交付被拒,只好作废一步再补一步。
7. **本体写入很重**:工厂 47 次、调研 58 次逐个文件 write,是耗时 3–7 倍的主要来源;实体没有用目录嵌套,也没有「良率」这类指标概念。
8. 技能(`.agents/skills`)一次都没写,会话二的复用全靠读文件。

## 建议的修法(待定)

按第一性原理,ClearAI 的价值在「谁判」与「留下什么」。现在这两件都取决于模型自己标的等级,而模型总会挑最省事的那级。
- 让唯一必然发生的独立判断(Conclude 评估)同时判每条判断;它判为支持的判断就升格成事实。等级只用来决定中途要不要额外派评估,不再卡升格。
- L4:在任务书或 Frame 里声明「不可重复的外部动作」时,AdvancePlan 交付其观测必须带人放行;做不到强制的部分在提示里说清,并在 DSH 上标出「未经放行的外部证据」。
- 评估者允许在工作区副本里重跑脚本(只读原工作区)。
- 判断要写成被检验的原说法,不写成自己的结论(提示与 Frame 说明各一句)。
- abandoned 也派一次评估,或把本体声明改成与代码一致。
- 产物允许写目录;本体写入允许一次写多个文件。
