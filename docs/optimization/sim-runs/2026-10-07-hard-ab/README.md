# 2026-10-07 两道难题的 A/B:知识 harness 版 ClearAI 对裸模型

代码:4c5b22e(状态卡在决策点给出本体与认识状态、可选对手判断、弱检验提示、评估者在副本里复跑)+ f26ad6a(新题 lh-cell)。
模型、评估者、评分者都是 Sonnet 5.5,思考中。每题 ClearAI 2 组、裸模型 2 组;评分者盲评,只看最后答复和交付文件。

## 结论

**这两道题上,ClearAI 没有测出正确性收益。** 电解液题打平,反应器题裸模型略好。代价是约 2.5–4 倍耗时、约 1.4–1.6 倍 token。

反应器的统一口径按答案:配方按**实际温度**代入真值,≥90.5 记 2、89–90.5 记 1、<89 记 0;漂移发现并纠正记 1、没纠正但点明影响记 0.5、被误导记 0。四个评分者各自用了不同满分,上表按同一口径重算,原始打分在各目录的 `grade.json`。

所有八组都是 Sonnet 的「诚实但保守」:没有一组把错的东西标成已核实(只有 rx-b1 一条「中心平台」被评分者判为过度自信)。最优点(电解液 A5/B2.1 约 1700 圈;反应器 T–cat 斜脊约 91%)八组都没找到。

一个旁证:两组 ClearAI 的反应器配方若温度计准(中试线就是准的),真值是 90.4% 和 89.9%,比两组裸模型(86.9%、87.5%)高;它们的中试也确实给了 91.2% 和 90.8%。但它们没把「中试比小试高约 3 个点」和「T_ref 低 8 °C」联系起来,所以配方仍被漂移拖到 OFAT 档。

## 机制观察

- **对手判断**:八组里 0 次使用。可选设计下模型不用,符合「不为竞争而竞争」;但也说明它在这两题上没有带来东西。
- **弱检验提示**:rx-c2 七次检验全是「支持」,卡片从第 3 次起一直提示「检验可能太弱」,模型没有改变做法。其余三组都有过「推翻」或「说不清」,提示没出现。
- **评估者复跑**:四次独立核验都在副本里重跑了脚本并复算数字,数字全部对得上;但四次都只核对交付是否兑现判据,**没有一次看出反应器的温度漂移**。评估者核的是「报告与数据是否一致」,不是「数据本身是否可信」。
- **事实与本体**:新工作区,没有以前的事实可显示;各组都没有建度量概念,「定义已变」仍未被触发。
- **L4 放行**:两组 ClearAI 都直接用命令跑了中试,没有走人放行(剧本断言失败,与 10-02 的 F5 相同,这次没修)。
- **剧本断言**:电解液两组 10/10;反应器 c1 10/11、c2 9/11(中试未经 L4;c2 只有支持)。

## 由此看下一步

难题上失分的地方,不是「没核」也不是「自信地错」,而是**探索不够深**(没找到交互项)和**异常没被当成线索**(漂移)。现在的卡片和评估者都在管「结论是否站得住」,不在管「还有什么没解释」。如果要让认识论真起作用,下一步该是把**没解释的观测**(T_ref 偏差、中试比小试高)作为一等状态挂在卡片上,直到被解释或被明确排除,而不是加更多关于判断的提示。这是推断,还没实现也没测。
