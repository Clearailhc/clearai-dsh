# 最终答复

**推荐配方**:c = 1.2 M,A = 2.5 wt%,B = 1.5 wt%,Tf = 40 °C。长测实测 **778 圈**(单次测量)。粗略可信范围约 700 到 850 圈。这是我的判断,不是统计区间:该配方只测了一次,没有重复,噪声未知。旁证是另一个配方 (1.2, 4, 1, 35) 长测 764 圈,和它相差不到 2%。它是已长测的三个配方里最好的,但**不能确证是全局最优**。

花费 36(12 次快测加 3 次长测),余 4,不够再做一次长测。报告在 report/formulation.md,数据和脚本在 lab/(quick.json、long.json、analyze.py、analysis_out.txt)。

## 各条结论的状态
- **快测外推能排出长测顺序:被推翻。** 快测外推最高的配方 (0.9, 4, 2.5, 50) 外推 1796 圈,长测只有 614 圈,是三个里最差的。外推排序和实测排序相反。
- **衰减近似线性、外推误差小于 20%:被推翻。** 三个配方的实测寿命都比外推低 27% 到 66%(实测/外推为 0.34、0.65、0.73)。保持率曲线前期缓、后期陡,是拐点型衰减。例如 614 圈那个配方,400 圈时 94.8%,600 圈时 82.4%,800 圈时 49.4%。
- **高 B 导致早拐点:说不清。** 高 B 配方内阻增长最大(16%)、寿命最短,但它同时 Tf = 50、c = 0.9,三个因素混在一起,3 次长测分不开。
- **100 圈内阻增长能预测长测寿命:说不清。** 三个点趋势相符,但样本太少。
- **推荐配方是全局最优:说不清。** 没有对四个因素逐个做长测拆分。
- **推荐配方的 700 到 850 圈范围:说不清。** 它只有一次实测,没有重复。

## 给你的建议
快测外推只能当粗筛,不能用来排名。后续预算应转向长测:在推荐配方附近一次只改一个量(优先 Tf 和 B),并做一次重复来量噪声。
