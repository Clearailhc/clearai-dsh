## 机制观察

- **未解释项真的被用了。** 四组 ClearAI 一共登记 29 条、消解 42 次(含评估者退回的)。c2、c3、c4 的漂移都是先作为未解释项挂在卡上,然后被一条判断解释掉(「控制器偏差约 8 °C」),再按它重算。c1 登记的 3 条都是收率形状,没碰 T_ref。
- **评估者查数据可信,起了作用。** c2、c3、c4 的评估者都主动核了中试没有参考温度这件事,标为「说不清」退回;c1 的两位评估者也没发现漂移,和模型一样漏了。
- **预期写得少。** `step/expected` 每组 0–4 次,多数在计划里一次写完。预期落空(收率不是单调升)在 c1、c3、c4 都被登记成未解释项,然后推翻对应判断。
- **不可逆拦截有效。** 四组都在 Frame 里声明了中试命令,`human/released` 各 1 次,没有绕过。
- **新问题:复合判断整条升格。** c1 和 c4 的判断写成「高温增杂质,且收率先升后趋平」一类复合句;评估者判「支持」时后半句其实被推翻了,整条照原话升成事实。c3 的评估者则因为后半句把整条判为推翻。需要在 Frame 的说明里要求「一条判断只说一件事」,或让评估者能部分支持。
- **过度自信。** c4 有 3 条被评分者判为「错而自信」:它把「最优点在杂质规格边界上」判为推翻,而真最优恰好在边界(0.499%)。依据是一次落在漂移期的点。其余七组 0–1 条。

## 电解液题

同样 ClearAI 4 组、裸模型 4 组,满分 5(配方真实寿命 2 分、识破快测外推 1 分、B 随 A 搭配 1 分、预期寿命误差 ±20% 以内 1 分)。

**打平:两边均分都是 2.25。** 八组都识破了快测外推,预期寿命都用长测实测值、都在 ±20% 以内;没有一组找到 A×B 的比例关系(B ≈ 0.4·A)和约 1700 圈的最优点。上一轮也是打平。

| 组 | 配方(c / A / B / Tf) | 真实寿命 | 得分 |
|---|---|---|---|
| ClearAI c1 | 1.15 / 4 / 1.6 / 33 | 1264 | 3 |
| ClearAI c2 | 1.2 / 2.5 / 1.5 / 40 | 772 | 2 |
| ClearAI c3 | 1.2 / 2.5 / 1.5 / 40(目标如实放弃) | 772 | 2 |
| ClearAI c4 | 1.2 / 2.5 / 1.5 / 40 | 772 | 2 |
| 裸 b1 | 1.2 / 2.5 / 1.5 / 40 | 772 | 2 |
| 裸 b2 | 1.2 / 2.5 / 1.5 / 40 | 772 | 2 |
| 裸 b3 | 1.1 / 4.5 / 1.5 / 52 | 1179 | 2 |
| 裸 b4 | 1.2 / 4.5 / 1.8 / 42 | 1465 | 3 |

- 这道题没有埋数据可信的陷阱,陷阱是「快测会骗人」和交互项,裸模型自己就识破了前者。未解释项每组 1–9 条,大多是长测曲线的拐点,登记了也没有引出拆 A、B 的实验。
- 六组落在同一个中心点(1.2 / 2.5 / 1.5 / 40),它是题目给的基线附近。两边都只用 3 次长测,探索同样浅。
- c3 没做到「推荐配方至少 2 次长测」,如实放弃结案;评估者在中途一步判过「花费超过登记的上限」,模型随后改了那一步的判据并留痕。
- c2 全程只用自判(没有 L3 检验),判官记为一条失败。
- 判官的「升格与证据等级自洽」不变量原来没考虑放弃结案(放弃的目标不升格),c3 撞上后补上了这一分支。
- 代价:模型子代理 token ClearAI 78k–97k,裸模型 58k–59k,约 1.5 倍,另加 1–2 次评估者。
