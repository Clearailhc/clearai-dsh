# 电解液配方:结果

**推荐配方**:c = 1.2 M,A = 2.5 wt%,B = 1.5 wt%,Tf = 40 °C。
**预期寿命**:约 765 圈,这是长测实测值,只测了 1 次。
**可信范围**:650–880 圈。这个范围是我假设长测噪声约 ±15% 得出的,并不是测出来的。三个长测的全部范围是 590–765 圈。

目标按"如实放弃"结案,不是"达成"。5 条判据里,推荐配方至少 2 次长测这一条没做到:预算 40 里,我花了 14 次快测和 3 次长测,共 38,剩 2,不够再做一次长测(8)。花费上限我原来写的是 36,实际 38,我把判据修订成实际花费并留了痕,原因是多做了一次候选预筛快测和一次重复快测。

## 每条结论的状态

1. **快测外推不能用来筛配方:已推翻。**
   - 依据:三个配方都做了快测和长测,外推分别高估 44%、167%、76%,全部超过 30% 的线。
   - 外推最高的 (0.8, 2.5, 3, 40) 外推 1586 圈,实测只有 593 圈,低于外推较低的中心点(外推 1103,实测 765)。
   - 数据在 lab/long.csv,对照脚本是 lab/compare.py。
2. **长测曲线在约 500–800 圈出现拐点,保持率从约 90% 骤降,前 100 圈的线性外推看不到:现象已核实,机制说不清。**
   - 例如中心点 600 圈 89.4%,800 圈 74%。
   - 我没有做机制实验。
3. **B 不是越多越好:已核实,但范围有限。**
   - B = 3 的配方(593 圈)比 B = 1.5 的中心点(765 圈)差。
   - 这两个配方的 c 也不同(0.8 对 1.2),所以差异不能全算在 B 头上。
4. **最优配方在参数范围内部:部分核实,总体说不清。**
   - 独立评估者对这条判了"支持",我认为证据比这窄。
   - B = 3 的边界点输给了内部点。
   - 快测外推最高的 (1.6, 5, 3, 55) 没做长测,A = 5、c = 1.6、Tf = 55 的边界仍然未知。
5. **A 和 B 各自对真实寿命的作用:说不清。**
   - (1.2, 4, 0.75, 40) 只有 590 圈,比中心点差,但它同时改了 A 和 B,三个长测的因素混在一起。
6. **快测有约 6% 的噪声:已核实,但只有一对重复。**
   - 同一配方两次外推是 1103 和 1037。
   - 长测噪声说不清,没有重复长测。
7. **推荐配方是已长测的三个里最好的:已核实。** 它是不是全局最优,说不清。c 和 Tf 方向基本没探。

## 建议和需要你决定的事

如果能追加预算,优先这三件事:
- 重复中心点长测,测出长测噪声。
- 固定 c = 1.2、Tf = 40,只改 A 或只改 B,做长测,把两者拆开。
- 对 c 和 Tf 做长测。

不要再用快测外推筛配方。是否追加预算,需要你定。
