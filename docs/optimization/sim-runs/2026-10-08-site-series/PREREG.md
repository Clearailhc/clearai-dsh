# 预注册:同一现场 3 题序列(0.5 阶段二的门槛)

开跑前写下,跑完不改。题目在 `tools/sim/long-horizon/site/`,答案在同目录的 `answer-s*.md`。
这一轮仍是开发集(题目由开发方出),只判阶段二的门槛,不当作有效性证据。

## 设置

- 同一套小试装置上三道反应题:A 线加氢、B 线酯化、C 线胺化,每题小试预算 30 次。三题共用一个工作区,前一题的文件都在。
- 现场共性(任务书不提):热电偶在第 20 / 12 / 8 次之后漂移(−7 / +6 / −8 °C 的读数误差),每第 5 次带参考读数;温度都和另一个因素沿斜脊耦合。
- 两组:ClearAI(本分支 0d1b2a8 之后的代码)与裸模型,各 3 个序列。模型、评估者、评分者都是 Sonnet 5.5,思考中。评分者盲评,只看这一题的最后答复与这一题的产物。
- 计分(每题满分 4):配方 0–2、漂移 0–1、耦合 0–1,见各题答案。

## 假设与门槛

- **H-机制**:ClearAI 的 3 个序列里,至少 2 个在第 1、2 题写下了经过核验的经验,且第 3 题的预期或计划里点名用了其中一条。
- **H2**:第 3 题得分,ClearAI 均分高于裸模型均分。
- **H2'(次要)**:第 3 题相对第 1 题的提升,ClearAI 大于裸模型。
- n = 3,不做显著性检验;差值和逐组数字照实报告。

## 止损

H-机制不成立,就说明经验没有进入决策点,先修机制再谈效果。H-机制成立而 H2 不成立,说明经验被用了但没换来更好的结论,记下来,不改题重跑。
