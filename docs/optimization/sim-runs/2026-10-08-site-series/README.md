## 结论

**H-机制成立(3/3)。** 三个 ClearAI 序列在第 1、2 题都写下了经过评估者核验的经验,第 3 题的计划或预期里都点名用了其中几条(见下文「机制」)。

**H2、H2′ 按预注册口径都成立,但差距小,而且全部来自漂移这一项。** 第 3 题均分 ClearAI 1.5、裸模型 1.17;第 3 题相对第 1 题 ClearAI +0.33、裸模型 −0.17。n = 3,不做显著性检验。

**配方没有变好。** 把交出的配方按实际温度代入真值,第 3 题 ClearAI 92.19 / 91.91 / 92.19,裸模型 93.03 / 91.65 / 92.30,裸模型均值还略高。六个序列都没找到温度与另一个因素的斜脊(耦合项第 3 题两边都是 0)。经验让「先看 T_ref、按实际温度表述」这件事带到了下一题,没有让探索变深。

## 机制

每个序列写下的经验(评估者判支持才落盘,其余在结案回执里列为「没写下的经验」):

| 序列 | 第 1 题 | 第 2 题 | 第 3 题 | 第 3 题里点名用到的 |
|---|---|---|---|---|
| sc1 | 2 | 2 | 3 | CreatePlan 预期「来自经验 l-7m96i2、l-2gbzvh」;RevisePlan 再用 l-2gbzvh |
| sc2 | 2 | 3 | 2 | RevisePlan 引 l-22w1rs、l-j4zln2、l-ssxl7y;AdvancePlan 引 l-j4zln2 |
| sc3 | 1 | 2 | 2 | CreatePlan 引 l-l0onyj、l-ptkawx、l-ywsiqc;Anomaly 引 l-ptkawx |

(计数只取模型自己的工具调用参数,不含卡片上的展示。)

- **经验确实被读到并用在预期里。** 例如 sc1 第 3 题第一步的预期写着「升温使杂质上升(B 线经验);收率可能因曲率出现 T×t 交互(来自经验 l-7m96i2、l-2gbzvh)」。sc2 第 3 题用 l-j4zln2(「首次最好值会比重复高」)写预期,结果落空,被登记成一条未解释项,交给人。
- **带过去的是做法,不是事实。** 漂移的方向和起点每题不同(−7 / +6 / −8 °C,第 20 / 12 / 8 次之后);经验写的是「早读 T_ref、按实际温度表述」,第 2、3 题的纠正都来自这条做法。sc1 第 3 题还写下一条坑:「漂移方向不一定偏高,别按旧线经验假设方向」。
- **经验没有教会找斜脊。** 有几条经验写的是「两水平主效应会骗人,先看交互与中心点曲率」,第 3 题也照做了(中心点邻域单因素),但没有一组去拆 T 与 cat 的耦合;耦合在第 3 题两边都是 0。
- **评估者核经验是有效的过滤。** 被判「说不清」或只是本次结论复述的提议没有落盘;落盘的都附了凭据(runs 文件的行号)与不适用的边界。
- **判官**:两次「不只有支持」失败(sc2 第 1 题、sc3 第 3 题,全部检验都是支持),其余不变量全过。

## 按止损规则

H-机制成立,H2 成立但差距只在漂移这一项、配方没变。按预注册:记下来,不改题重跑。下一步的问题不在「经验能不能带过去」,而在探索深度:经验和本体都没有让模型去拆耦合。
