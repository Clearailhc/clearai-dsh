# 均值独立核对

## 两条路径

- **路径 A(主计算)**:`python lab/analyze.py` —— Python `csv.DictReader` 逐列累加、除以 n、`round(…, 6)`,结果写入 `lab/means.json`。
- **路径 B(独立复算)**:不经过任何 Python 代码,直接用 awk 一行式读 `lab/raw.csv`:

```bash
awk -F, 'NR>1{a+=$1;b+=$2;c+=$3;n++} END{printf "%d %.6f %.6f %.6f\n", n, a/n, b/n, c/n}' lab/raw.csv
```

  输出:`20 52.253000 50.772000 -1.925500`

为便于逐字对照,路径 A 的值统一格式化为 6 位小数(`"%.6f" % means[k]`)。

## 逐列对照(6 位小数)

| 列 | 路径 A:lab/means.json | 路径 B:awk | 结果 |
|---|---|---|---|
| n | 20 | 20 | 一致 |
| a | 52.253000 | 52.253000 | 一致 |
| b | 50.772000 | 50.772000 | 一致 |
| c | -1.925500 | -1.925500 | 一致 |

## 结论

3 列均值与行数 n 在 6 位小数下两条路径全部一致;按事先写下的判据,这支持假设 h-t7uxdy(推翻条件「任一列不同」未出现)。
