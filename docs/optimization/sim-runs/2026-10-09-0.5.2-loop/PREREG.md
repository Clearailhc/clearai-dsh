## 设置

- 四题依次在同一工作区里做,前一题的文件都在:
  - t1 `lh-loop-1` A 线优化(热电偶第 20 次后漂移 7 °C,温度与催化剂耦合,含水 w 无影响),预算 30,满分 5;
  - t2 `lh-loop-2` A 线换催化剂批次(同一支热电偶从第 1 次起偏 7 °C,斜脊右移 6 °C),预算 30,满分 4;
  - t3 `lh-loop-3` B 线(另一套装置,无漂移、无耦合,最优可分离),预算 30,满分 4;
  - t4 `lh-loop-4` A 线量产收率下滑定位(漂移由 7 °C 增至 13 °C;含水升高、换班组是同时发生的干扰项),小试预算 12,满分 4。
- 两组,各 3 个序列:C = ClearAI 0.5.2(本分支),A = 裸模型(同一工作区,无额外机制)。
- 模型、独立评估者、评分者都是 Sonnet 5.5(claude-sonnet-5-5),思考强度中等。评分者盲评,只看这一题的最后答复与这一题的产物。
- n = 3,不做显著性检验;逐组数字照实报告。

## 机制指标(C 组,从账本机算)

- M1 回灌完整:每次结案,账上的被推翻判断、开着的未解释项、测量类反常,落成条目的比例。
- M2 取用被使用:t2–t4 中,至少一条已有条目出现在判断的 `uses` 里的题所占比例。
- M3 适用性判对:t3 中被引用的 A 线条目被判为范围外(或条件未声明)的比例;任何一题中,范围外条目未经检验即进入结论的次数。
- M4 负向复用:t4 中只为检验 w(其余量不变、只改 w)所花的小试次数。
- M5 范围误撤回:范围内成立的事实被范围外数据撤回的次数。
- M6 静默结案:评估者提出、未处理而结案的问题数。

## 止损线(任一不满足即停止并重新设计)

| | 条件 | 不满足说明 |
|---|---|---|
| S1 | M1 ≥ 95%,M2 ≥ 80%,M5 = 0,M6 = 0 | 闭环机制本身没有接上 |
| S2 | t3 中误用 A 线条目导致结论出错(答案 b1 的「误用」一项):C 组 0 次 | 适用性检查无效,存下的知识会伤人 |
| S3 | t2–t4 均分(各题折算到满分 4)C ≥ A + 0.5,且 t2–t4 相对 t1(同样折算)的提升 C 大于 A | 沉淀与取用没有带来更好的结果 |
| S4 | 所用实验次数 C 的均值 ≤ A 的 80%:t2 取「第一次达到 ≥ 90.4% 的小试序号」(未达到记 31),t4 取 M4 | 复用没有节省预算 |
| S5 | 「错而自信」条数(评分 `overconfident` 之和)C 不多于 A | 可信性退化 |
| S6 | C 组含评估者的总 token ≤ A 组 2.5 倍 | 投入产出不达标,先裁剪 |
