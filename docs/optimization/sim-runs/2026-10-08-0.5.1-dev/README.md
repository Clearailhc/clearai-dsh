评分口径按[升级计划](../../0.5.1-plan/upgrade-plan.zh-CN.md) §五修订后的版本:反应器配方一律按实际温度代入真值;漂移项为纠正 1、发现未纠正 0.5、未发现且结论不受影响 0.5、被误导 0。

## 结论

**止损线没有通过,按计划应停下重新设计,不进入正式验证。** 四条止损线中只有「反应器配方真值均值不低于裸模型」达到;机制指标前三项、反应器漂移纠正、耦合结构、成本四条都没有达到。

正确性上,ClearAI 在反应器题领先,其余三题与裸模型持平或略高;两组都几乎没有「错而自信」。

## 良率归因三连

- 四个序列在会话一都找到了 B0723 × 湿度 > 65% 的真因,都识破夜班、S-B 整体、操作工、温度是混杂;都没有指出 OP15 约 0.4 个点的小差异。会话二都定位到 L2-ST3 退化并撤回「停用 B0723 即恢复」;会话三都给出有条件恢复 S-B。两组没有可分辨的差别。
- 「定义已变」仍然没有触发:良率口径改为最终合格率后,两个 ClearAI 序列都没有出现这一状态。
- 跨会话复检有一次走通但结果有误:c1 会话二用九月数据复检八月事实,系统问人后撤回了「B0723 是八月下滑主因」这条在八月范围内成立的事实(模拟应答默认选第一项「撤回此事实」)。事实文件的 `scope` 字段里写的是推翻条件,不是适用范围(月份、批次),所以复检时无法区分「换了范围」与「被推翻」。
- 反向的问题也出现了:c2 结案时把字面成立、实际只由一个批次造成的「S-B 来料一次合格率低于 S-A」升格为事实(f-b4h3zq)。会话二、三的数据都与它矛盾,但没有走复检,只在最终答复里请人决定是否撤回。

## 固态电池调研

- 四组的十条宣称核实都很准,失分集中在第 7 条(口径之争)和第 8 条(本田示范线是否按期开工)。ClearAI 两组第 7 条判为「有争议」或给出口径说明,c2 被评为一条错而自信。
- 两组 ClearAI 都在结论中把半固态与全固态分口径作答;评估者对「硫化物最先上车」判为不确定(依据只有公司目标),对「半固态是唯一上车路线」指出聚合物公交已商用。

## 机制观察

- **两道新检查没有起作用。** 测量门与停止检查在全部 16 次 ClearAI 会话里拦截 0 次。测量门的漏洞是只查声明为「量」的概念;停止检查只看模型自己登记、且声明了所涉对象的未解释项,评估者在审计中提出的未解释项不在其中。
- **未解释项仍是 ClearAI 唯一稳定起作用的部分。** 反应器 c2、c3 的漂移都是先登记为未解释项、再被一条判断解释掉;c4 登记了「装置漂移」却没有追到温度。
- **预测过半仍凭直觉。** 43 条预测中 23 条标为直觉;良率题 c1 三个会话共 1 条预测。各候选预测相同而无法区分的步骤只有 3 次(共 83 步)。
- **事实缺少适用范围。** 见良率题两条:一条范围内正确的事实被撤回,一条过度概括的事实被保留。
- **成本主要在模型自身。** 评估者只占 ClearAI 成本的 13%–24%;模型自身的处理量是裸模型的 4–6 倍,来源是更长的回合与更大的上下文(系统提示、状态注入、工具结果)。
