# 均值独立核对

## 两条路径

- **路径 A(被核对方)**:`python lab/analyze.py` → `lab/means.json`(Python `csv.DictReader` 累加,`round(..., 6)`)。
- **路径 B(独立核对)**:mawk 1.3.4 一行式,不经过 Python,也不读 `means.json`:

```bash
awk -F, 'NR>1{a+=$1;b+=$2;c+=$3;n++} END{printf "a=%.6f b=%.6f c=%.6f n=%d\n",a/n,b/n,c/n,n}' lab/raw.csv
```

原样输出:

```
a=46.147000 b=52.050000 c=0.367500 n=20
```

## 逐列对照

| 列 | means.json(路径 A) | awk(路径 B) | 绝对差 | 判定(≤ 1e-6 为一致) |
|---|---|---|---|---|
| a | 46.147 | 46.147000 | 0 | 一致 |
| b | 52.05 | 52.050000 | 0 | 一致 |
| c | 0.3675 | 0.367500 | 0 | 一致 |

awk 计到的数据行数 n = 20,与 raw.csv 的数据行数一致。

## 结论

三列在两条独立路径下的均值逐列相同(绝对差均为 0,不超过 1e-6 的阈值)。
