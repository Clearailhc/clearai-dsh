# ClearAI 0.5 升级计划:让本体论与认识论真正起作用

2026-10-07 定稿(在线版:https://claude.ai/code/artifact/a29fbbe5-5b9e-407d-ba92-952a86597370)。详细设计见 [meta-design.zh-CN.md](meta-design.zh-CN.md)。

## 结论与目标

**0.5 的目标是可信、价值可验证的 DSH 本体论插件。** 认识论循环是核心 loop:一边用本体分析和探索,一边把检验过的结果写回,构建可信的本体;经验跨任务沉淀,下次在决策点推到眼前。

「真的有用」用三条可测判据来定义,都以裸模型加一个笔记文件作对照:

| 判据 | 怎么量 | 目标 |
| --- | --- | --- |
| 抓异常 | 埋了陷阱(漂移、代理指标失真)的题里,陷阱被发现并纠正的比例 | ClearAI 至少 3/4,并且明显高于对照组 |
| 越做越好 | 同一现场的任务序列里,第 3 题相对第 1 题的得分提升 | ClearAI 的提升明显大于对照组 |
| 不添乱 | 一次性的简单题上的正确率和成本 | 正确率不低于裸模型,耗时不超过 2 倍 |

前两条做不到,就说明还是空架子。第三条做不到,说明架子太重。

## 第一性原理:专家比新手多了什么

外挂机制只有三条路能超过裸模型:补它上下文里没有的信息;给它一双独立的眼睛;改变它下一步做什么。只改变它记了什么,不算。

| 专家有的 | LLM 的现状 | ClearAI 该补的 |
| --- | --- | --- |
| 一个很快的预期,数据违背它就觉得「不对劲」 | 不持有显式预期,什么都能解释过去 | 动手前写预期,落空就记「未解释」 |
| 一套分类,决定看什么(例如「热电偶会漂」) | 书本知识很宽,但不会自己去用 | 本体里的概念、因果和测量通道,在决策点推到眼前 |
| 挂在具体对象上的经验(「2 号釜要核温度」) | 每次会话都从学徒重新开始 | 结案时沉淀经验,挂到实体和概念上 |
| 知道何时信直觉、何时实测、何时找人 | 诚实、校准良好,这一点不缺 | 只留独立评估和人放行两道硬门 |

推论:第一次进一个新领域时,两边都是学徒,ClearAI 能多出来的只有「对反常的纪律」。真正拉开差距的是同一现场的第 N 个任务,因为裸模型永远是学徒。

## 现状诊断

三轮长测(10-02 五题、10-03 工厂复测、10-07 两道难题)里,只有独立评估和可撤回的事实证明过自己在做功,其余都是空架子。

| 机制 | 证据 | 判定 |
| --- | --- | --- |
| 独立评估 | 10-02 反应工艺题唯一一次胜出(2.5 对 0.5),靠评估者顺手指出漂移;10-07 四次评估都复跑对上了数,却没人问数据本身可不可信 | 做功,但查错了对象 |
| 事实与 retests | 工厂复测里旧事实被推翻、问人、撤回,全链路跑通 | 做功,但只存结论,不存经验 |
| 本体 | 47–64 次写入,没有一次改变过模型的下一步;「定义已变」一次没触发 | 空架子,是主要成本 |
| 等级 L0–L2 | 模型一律自标 L1/L2 | 空架子 |
| 对手判断、弱检验提示 | 8 组里对手 0 次;提示连续出现也没改变做法 | 空架子 |
| L4 人放行 | 两轮里中试都用 Bash 绕过 | 形同虚设 |
| 技能沉淀 | 结案后提示写 SKILL.md,长测里几乎没写 | 空架子 |

裸模型已经诚实、校准良好:10-07 的 8 组里「错而自信」只有 1 条。失分的真正原因只有两个:异常看见了却被解释过去,以及探索太浅、没找到交互项。

## 改动方案

五项改动围绕一个闭环:预期 → 观测 → 发现反常 → 解释或排除 → 沉淀成经验 → 下一题的预期。前三项管单次任务,第四项管跨任务积累,第五项是安全底线。

### ① 预期与「未解释」

- CreatePlan 的每一步可带 `expect`:动手前写下预期结果,并尽量引用本体里的关系或经验。
- AdvancePlan 的观测可登记未解释项:哪里和预期不符,或哪个读数说不通。
- 未解释项一直挂在卡片上,只有三种去处:被一条判断或关系解释;写明理由排除;交给人。
- 不加新门:结案时未解释项随交付一起交给评估者(见 ③)。
- 改哪里:`clearai-kernel.js` 的 CreatePlan/AdvancePlan schema、`fold.js` 新增 `anomaly/*` 变更、`knowledge-view.js` 的卡片、提示词一段。

### ② 本体只留能产出预期的东西

- 概念分类别 / 度量 / 现象;度量必须写定义和单位,「定义已变」才有东西可抓。
- 关系带方向和大致形状(单调、有峰、阈值),这就是预期的来源;新增「测量」关系:哪个仪器测哪个量、有没有参考读数。
- 实体保留,作为本体的实例,新增带日期的历史。
- 只有被预期、判断或经验引用到的本体项才上卡片;本体提纲和计数从卡片上去掉。

### ③ 评估者改查「什么还没解释」

- 保留判据核对和复跑。
- 新增两问:原始数据里有没有模型没登记的异常;每条已排除的未解释项,理由站不站得住。
- 评估者新发现的异常变成未解释项退回给模型。
- 改哪里:`evaluatorPrompt` 与裁决 schema 加 `anomalies` 字段。

### ④ 经验沉淀(跨任务积累)

- 结案时,除了升格事实,再提炼经验:一句话的教训,挂在实体或概念上,带证据和边界。
- 四类:坑、要核的读数、会骗人的捷径、先验。
- 下一题碰到同一实体或概念,就把经验推到卡片上。
- 经验经独立评估才生效,可被推翻、撤回;存在 `clear/knowledge/lessons/`。
- 技能是「怎么做」,经验是「要留意什么」。

### ⑤ 不可逆动作的人放行(L4)

- Frame 里声明不可逆的动作及其命令特征。
- `tools/pre-execute` 钩子对匹配的 Bash 命令拒绝执行,直到人放行。

## 删掉什么

| 删掉 | 理由 | 被什么取代 |
| --- | --- | --- |
| 对手判断(`rival`/`split_by`) | 8 组里 0 次使用 | 预期落空天然就需要另一种解释 |
| 弱检验提示 | 连续出现也没改变做法 | 预期写在前面,弱检验一眼可见 |
| 卡片上的本体提纲与计数 | 不改变下一步 | 只显示被引用的本体项和经验 |
| L0–L2 的细分 | 模型一律自标 L1/L2 | 合并成「自判」,只留自判 / 独立评估 / 人放行三档;旧会话读取时映射,不迁移 |

## 怎么证明

1. **预注册。** 开跑前把假设、指标、答案、样本量和统计方法提交到仓库,跑完不改。H1 陷阱发现并纠正率高于对照;H2 同一现场第 3 题相对第 1 题的提升大于对照;H3 简单题上不劣于裸模型(非劣效界限事先定)。
2. **题目与开发隔离。** 反应工艺和电解液两题只作开发集。证据题由另一个不看 ClearAI 代码的代理出:3 个现场各 3 题,同类陷阱在后题换形式复现,另加 3 道简单题。题目和答案在开跑前封存。
3. **对照组。** 裸模型;裸模型加笔记(自己读写 notes.md);ClearAI。同模型(Sonnet 5.5,思考中)、同工具、同预算、同时间上限。
4. **消融。** 去掉预期与未解释、去掉经验、去掉独立评估。少了不掉分的,按奥卡姆砍掉。
5. **样本量。** 每组每题 6 次,顺序随机。主实验 3 × 12 × 6 = 216 次,消融 3 × 9 × 6 = 162 次。
6. **评分客观优先。** 能用真值函数算的就机算;要人判的部分由两位盲评者独立打,交付物去掉 ClearAI 术语,报告一致性,分歧由第三位裁。
7. **统计。** 按题配对,报均值差与 95% bootstrap 置信区间,加置换检验。H1、H2 的区间不含 0 才算成立,H3 用非劣效检验。
8. **全量公开。** 每次运行都进 docs/,包括失败的;成本和得分一起报。

**止损线:** 阶段一在开发集上先跑小样本(每组 4 次)。ClearAI 在反应工艺题上纠正漂移的次数没有从上轮的 0/2 升到至少 3/4,就停下来重新想。开发集结果只用来决定停不停,不当作有效性证据。

## 顺序与版本

1. **阶段一(0.4.1):** ① + ③ + 删掉对手判断和弱检验提示 + L0–L2 合并 + ⑤ + 宿主升级到 DSH 0.2.x。门:开发集 A/B,漂移纠正至少 3/4,中试不再绕过人放行。
2. **阶段二:** ② + ④。门:单个现场的 3 题序列里,第 3 题确实用上了前两题的经验。
3. **阶段三:** 正式验证(主实验加消融)。门:预注册的 H1–H3。通过就发 0.5.0,记录写进 docs/cases/。

**2026-10-08 调整:** 阶段二的开发集结果出来后(见 [现场序列](../sim-runs/2026-10-08-site-series/README.md)),决定先把阶段一、二作为 0.5.0 发布。正式验证顺延到之后的版本;探索深度另行设计,草稿见 [exploration-depth.zh-CN.md](exploration-depth.zh-CN.md)。
