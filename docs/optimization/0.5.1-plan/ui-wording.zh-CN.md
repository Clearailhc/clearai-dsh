# 界面中文用语规范

2026-10-08。用户反馈:界面中文太像直译,读起来别扭(如「凭什么」「还不确定的」「要你定的」「从哪来」「预期」「注意」)。本文统一界面用语,探索货架样稿已按此改完;改代码时,现有界面一并按下表替换。

## 原则

1. 用书面语和行业通用术语,不用口语、俚语和比喻(「摸底」「坑」「追」「对得上」)。
2. 标签用名词短语(「依据」「局限」),不用问句或半句话(「凭什么」「从哪来」)。
3. 称呼用户一律用「您」;只在确需用户操作时才称呼,其余用无主语句。
4. 状态词用「已 / 未 / 正在」体系,同一类对象的状态词成套出现。
5. 数字带量词和单位(「判断 9 条」「实验 18 次」「93%」),不写裸数。
6. 变量写全称(「催化剂用量」「压力」「反应时间」),不在界面上用 cat、P、t 这类缩写;仪表位号(TC-1、T_ref)保留。
7. 每句话把条件和结论都说完整,不省略主语后的关键限定(如「两个假设的预测值相差约 5 个百分点,远大于测量噪声」)。

## 新增概念的用语

| 概念 | 用语 | 状态词 |
|---|---|---|
| 两种工作方式 | 广度调研 / 定向求解(货架类型称「调研型」「求解型」) | — |
| 调研的分块 | 调研板块 | 未开始 / 调研中 / 已厘清 |
| 一个问题下的几种可能 | 候选假设 | 考察中 / 已排除 / 已采纳;另有「暂不考察」 |
| 过程中新出现的问题 | 新发现的问题 | 按钮:立为问题 / 暂缓 |
| 某次实验前写下的结果 | 预测(若「X」成立,预测……) | — |
| 候选假设的展开项 | 提出依据 / 预测 / 局限 / 关联记录 / 排除依据 / 采纳依据 / 关联判断 / 对结论的影响 / 引用经验 | — |
| 过程区 | 过程记录 | — |
| 结论四部分 | 结论 / 依据 / 尚未确定的事项 / 待您决策 | — |
| 依据旁的跳转 | 查看探索记录 | — |
| 本体货架列表 | 已确立的事实 / 经验 | — |
| 经验的类别 | 前置核查 / 常见误区 / 不可取的捷径 / 先验知识 | 原为 先核 / 坑 / 别走的捷径 / 先验 |
