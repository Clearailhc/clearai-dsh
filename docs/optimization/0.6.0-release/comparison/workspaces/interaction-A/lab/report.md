# 响应面优化报告（x, y ∈ [0,1] 收率最大化，杂质 ≤ 0.115）

## 1. 结论

最终提交点：**x = 0.491，y = 0.495**。

该点是二次交互响应面的连续最优点（0.4908, 0.4949）按实验坐标四舍五入后的点；在该坐标上完成了两次独立的 `full` 验证，读数分别为 95.152% 和 94.787%，杂质分别为 0.08658 和 0.08709，均低于 0.115。模型预测收率 95.163%，预测杂质 0.08683，杂质保守 95% 上界 0.10766。

## 2. 目标、变量与单位

- 目标：最大化收率 `value`。
- 变量：`x, y ∈ [0,1]`，均为归一化配方坐标。
- 约束：`impurity ≤ 0.115`（杂质以 fraction 计）。
- 收率单位：`%`；杂质单位：fraction。
- 仪表：`original`；`metric = yield`。
- 校准口径：`calibrate` 返回 `offset = 0`、`unit = normalized x`；在两个不同位置校准均为 0，因此未对原始读数做任何平移/缩放修正，直接使用 `value` 和 `impurity`。

## 3. 实验与预算

初始 `initial.json` 提供 9 个 `full` 读数（3×3 网格：x,y ∈ {0.1, 0.5, 0.9}），不计入本次新增消耗。新增实验如下：

| 校准 2 | calibrate | (0.1, 0.9) | 2 | `lab/cal-1.json` |
| 内圈 1 | full | (0.3, 0.3) | 3 | `lab/full-0.3-0.3.json` |
| 内圈 2 | full | (0.7, 0.3) | 3 | `lab/full-0.7-0.3.json` |
| 内圈 3 | full | (0.3, 0.7) | 3 | `lab/full-0.3-0.7.json` |

所有读数均以原始 JSON 保存，未覆盖 `initial.json`，未把校准记录当作测量值合并进拟合。`quick` 的 `noise_sd = 0.45`，明显高于 `full` 的 0.18，因此只作为一致性检查，不进入主拟合。

## 4. 模型与参数

采用归一化坐标 `u = 2x - 1`、`v = 2y - 1` 上的二次交互响应面。使用 17 个 `full` 观测（9 个初始 + 8 个新增）拟合：

### 4.1 收率模型

```
yield(u,v) = 95.16124
             - 0.17702 u
             - 0.00189 v
             - 6.58244 u²
             - 5.84459 v²
             + 6.37438 u v
```

- 观测数 n = 17，参数数 6，自由度 11。
- 拟合残差标准差 σ = 0.2169；收率 RMSE = 0.1745，与 `full` 的 noise_sd = 0.18 一致。
- 留一交叉验证 RMSE：交互模型 0.264，显著优于加性模型 4.085；因此选择交互模型。

### 4.2 杂质模型

```
impurity(u,v) = 0.087346
                + 0.014973 u
                + 0.024401 v
                + 0.007055 u²
                + 0.000874 v²
                - 0.000234 u v
```

- 杂质拟合 RMSE = 0.000453，远小于保守使用的 0.01 噪声尺度。
- 在最优点预测杂质 = 0.086824，保守 95% 上界 = 0.107663 < 0.115。
- 约束在最优区域内不活跃，最优解由收率面本身决定。

### 4.3 连续最优解

令梯度为零：

- u* = -0.01838，v* = -0.01018
- x* = 0.49081，y* = 0.49491
- 预测收率 = 95.16288%
- 顶点标准误（u, v）= (0.01208, 0.01326)，换算到物理坐标约为 (0.0060, 0.0066)
- 95% 预测区间 = [94.711, 95.615]%

## 5. 验证与中心点比较

在提交点 (0.491, 0.495) 的两次 `full` 读数：

| 文件 | 收率 | 杂质 |
|---|---:|---:|
| `lab/full-opt-1.json` | 94.787% | 0.08709 |
| `lab/full-opt-1-rep.json` | 95.152% | 0.08658 |

两次均可行（杂质 < 0.115），收率差异 0.365%，与 `full` 噪声（σ = 0.18，两次差的标准差约 0.25）相符。

中心点 (0.5, 0.5) 的两次 `full` 读数为 95.445% 和 95.253%（均值 95.349%），杂质均约 0.08786。中心点的实测收率略高，但：

- 中心点位于拟合顶点的 95% 置信椭圆内（Mahalanobis 距离平方 2.97，2 自由度卡方生存概率 0.227）；
- 二次面在顶部非常平坦，中心与顶点的预测收率差仅约 0.0017%，远小于测量噪声；
- 因此中心点与连续顶点在统计上不可区分。本次仍提交模型顶点，因为它是对“收率最大化”的点估计；若要求“实测最高且可行”，中心点 (0.5, 0.5) 是同等的稳健备选。

网格推荐点 (0.49, 0.49) 也做了 `full` 验证：收率 94.989%，杂质 0.08657，与模型预测一致。`quick` 在中心的结果为 95.027%（noise_sd 0.45），与 `full` 结果在快速模式的噪声范围内一致。

## 6. 仪表口径与数据处理

- 仪表名：`original`；指标：`yield`。
- 收率读数单位：`%`；杂质读数单位：`fraction`。
- `calibrate` 在 (0.5,0.5) 和 (0.1,0.9) 两个位置均返回 `offset = 0`，`unit = normalized x`；没有证据表明存在需要修正的加性偏差，故未做校正。
- `full` 模式 `noise_sd = 0.18`，成本 3；`quick` 模式 `noise_sd = 0.45`，成本 1；`calibrate` 成本 2。
- 所有实验输出均保留在 `lab/`，原始 `initial.json` 未修改；派生输入、模型和拟合结果分别保存为 `lab/input-*.json`、`lab/model-*.json`、`lab/final-analysis.json`。

## 7. 局限

1. 模型是二次响应面；预测不是测量，且不能证明因果有效性。真实面若含高阶项，顶点位置可能有偏。
2. 最优区域非常平坦；坐标标准误约 0.006–0.007，中心点与顶点在统计上等价。收率对顶点附近 0.01–0.02 的坐标偏移不敏感。
3. 大部分设计点位于 [0.1,0.9]²；最优点在内部，未依赖边界外推。观察到的最优区域覆盖充分。
4. 杂质模型拟合残差很小，但预测上界使用了保守的 0.01 杂质噪声尺度；即便如此上界仍低于 0.115。
5. 预算剩余 1 单位，不足以再进行一次 `full`（成本 3）；没有用 `quick` 替代最终验证，因为其噪声是 `full` 的 2.5 倍。
6. 测量噪声和可能的模型失配意味着实测收率在 94.7–95.6% 区间内波动；提交点附近的两次实测均在该区间内。
