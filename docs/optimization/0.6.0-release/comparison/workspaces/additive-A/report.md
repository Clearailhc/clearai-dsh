# 加性响应面优化报告（x,y∈[0,1]，杂质≤0.115）

## 1. 最终结论

- 提交点：**x = 0.5，y = 0.45**
- 该点有两次独立的 **full** 原始读数：
  - `lab/full-01.json`：收率 95.17854%，杂质 0.085114
  - `lab/full-07.json`：收率 95.54121%，杂质 0.085162
  - 两次收率均值 95.35988%，杂质均值 0.085138；两次杂质都低于 0.115。
- 用全部 16 条 full 观测拟合的加性二次面给出的最优点为 (0.50181, 0.45374)，预测收率 95.19674%；提交点 (0.5,0.45) 的预测收率为 95.19633%，与模型最优点仅差约 0.0004 个百分点，实际不可区分。因此选择已被 full 实测验证的 (0.5,0.45)，而不是未实测的连续最优点。

## 3. 模型参数

按 `method/response_surface.py` 的口径，把坐标缩放到 u=2x−1、v=2y−1，拟合加性二次面：

`yield = b0 + b1·u + b2·v + b3·u² + b4·v²`

最终 full 数据（16 条）的系数为：

| 参数 | 估计值 |
|---|---:|
| b0（截距） | 95.147584 |
| b1（u） | 0.048010 |
| b2（v） | -1.060733 |
| b3（u²） | -6.641257 |
| b4（v²） | -5.732233 |

- 拟合残差 RMSE ≈ 0.1487，留一交叉验证 RMSE ≈ 0.1587，与 full 的 `noise_sd=0.18` 同量级。
- 加入 u·v 交互项的模型 LOO RMSE ≈ 0.1810，比加性模型差；交互项估计约 -0.012±0.122，不显著。`method/response_surface.py` 因此选择 **additive** 模型。
- 由二次面顶点公式得到 x*=(1+b1/(2·6.641257))/2=0.50181，y*=(1+b2/(2·5.732233))/2=0.45374（b2 本身为负，故 v* 为负）。

杂质面（同口径加性二次）系数为：

`impurity = 0.087580 + 0.015367·u + 0.024289·v + 0.008443·u² + 0.000114·v²`

- 拟合残差 RMSE ≈ 0.0007（杂质分数），LOO RMSE ≈ 0.0011。
- 在 (0.5,0.45) 处预测杂质 0.08515；实测两次为 0.08511/0.08516。
- `method/response_surface.py` 默认 `impurity_noise_sd=0.01` 时，该点的保守预测上界为 0.10609（见 `lab/model-full06.json`），仍低于 0.115。

## 4. 仪表口径与校准

- 所有读数均为同一台 **original** 仪表；`metric=yield`，收率单位是 **%**，杂质单位是 **fraction**。
- full 的 `noise_sd=0.18`（收率百分点）；quick 的 `noise_sd=0.45`。quick 并非另一台已标定仪表，而是同一 original 仪表的高噪声快速模式，因此 quick 只用于边界筛选，不并入最终 full 拟合。
- 在 (0.5,0.45) 做了两次 calibrate：`lab/cal-01.json` 与 `lab/cal-02-final.json`，均返回 `instrument=original, offset=0`（单位为 normalized x）。因此没有对任何读数施加偏移修正；calibrate 记录只作为仪表证据，没有当作收率观测追加。
- 在 (0.5,0.45) 的 full 与 quick 读数相差 0.230 个百分点，小于 quick 的噪声量级，未见系统性偏移。

## 5. 验证

- 最终提交点 (0.5,0.45) 被 **full** 模式直接测量了两次，不是模型外推，也不是 quick 读数。
- 两次收率差 0.363 个百分点；独立重复差的标准差约为 √2×0.18=0.255，约 1.4 个标准差，属于统计噪声范围。
- 两次杂质均约 0.08514，低于 0.115 约 0.0299（分数），有明确裕量。
- 选点流程：`lab/model-full06.json`（当时剩余预算 5）推荐 (0.5,0.45)；随后 `lab/full-07.json` 用 full 复核该点；最后 `lab/model-final.json` 用全部 full 数据重拟合。由于此时剩余预算仅 2、小于一次 full 的 3，最终模型文件的 `recommendation` 为 null（预算门控），这不是拟合失败；最终决策由已 full 验证的 (0.5,0.45) 给出，`best_measured` 也指向该点。

## 6. 局限

1. 模型是经验性加性二次响应面，只描述当前实验域，不能证明因果机制。
2. full 设计覆盖 x,y∈[0.1,0.9]；边界只用四条 quick 中点筛选，0 和 1 附近的高阶行为仍有不确定性。虽然边界读数明显更低，但不能严格证明全局最优。
3. 收率噪声 `noise_sd=0.18`；单次读数会有约 ±0.35（95%）波动，最终点两次 full 的差异即来自该噪声。模型预测不是测量。
4. 杂质上限 0.115 是硬约束；模型对杂质拟合很好（残差约 0.0007），但默认 0.01 噪声口径下的保守上界约 0.106，仍不能替代工艺波动下的保证。
5. 只有一台 original 仪表、且只在一个位置做了校准；offset=0 的结论不能外推到替换仪表或其他位置。
6. quick 读数噪声较大，且未按异方差加权并入最终拟合；它们只作为边界筛选证据。
