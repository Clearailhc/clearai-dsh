# 添加剂收率优化报告

## 1. 最终结论

- **建议参数：`x = 0.508`，`y = 0.453`**（归一化坐标，范围均为 `[0,1]`）。
- **最终全量测量（full）读数：收率 `95.5224 %`，杂质 `0.084766`**；杂质远低于上限 `0.115`，余量约 `0.0302`。
- 以全部 17 条全量观测重新拟合的二次响应面，连续最优约在 `(0.5079, 0.4532)`，预测收率 `95.372 %`，预测杂质 `0.08501`。
- 最终点附近 4 次全量独立读数分别为 `95.406`、`95.310`、`95.487`、`95.522 %`，均值 `95.431 %`，样本标准差 `0.094 %`。最终点已做 full 验证，不是仅靠模型外推。

## 2. 实验设置与预算

| 项目 | 数值/说明 |
|---|---|
| 变量范围 | `x,y ∈ [0,1]`，归一化坐标 |
| 目标 | 最大化收率 `value`（单位 `%`） |
| 杂质约束 | `impurity ≤ 0.115`（分数，不是百分数） |
| 初始数据 | `initial.json`，9 条 full 观测，未修改 |
| full 成本/噪声 | 3 单位/次，`noise_sd = 0.18` |
| quick 成本/噪声 | 1 单位/次，`noise_sd = 0.45`，仅用于侦察，未并入全量拟合 |
| calibrate 成本 | 2 单位/次 |
| 总预算/实际支出 | `30 / 30` 单位，剩余 `0` |
| 支出构成 | full 8 次 = 24；calibrate 2 次 = 4；quick 2 次 = 2；合计 30 |

## 3. 响应面参数

使用 `method/response_surface.py`（版本 `0.5.2-rc.1`）。拟合坐标取

```text
u = 2x - 1,  v = 2y - 1
```

### 3.1 收率模型（选中的 additive 二次模型）

```text
yield(u,v) = 95.321928
           + 0.211991 u
           - 1.027740 v
           - 6.745066 u^2
           - 5.489505 v^2
```

- 留一交叉验证 RMSE：**0.1803 %**（与 full 的 `noise_sd = 0.18` 相当）。
- 对照 interaction 模型（增加 `u*v`）的 LOO RMSE 为 **0.2336 %**，交互项系数仅约 `0.0568`，未达到噪声可分辨水平；按方法规则选择 additive 模型。
- 换算到原始归一化坐标：

```text
yield(x,y) = 83.903105
           + 27.404247 x
           + 19.902541 y
           - 26.980264 x^2
           - 21.958020 y^2
```

连续驻点：`x = 0.50786`，`y = 0.45320`，预测收率 `95.372 %`。

### 3.2 杂质模型（二次）

```text
impurity(u,v) = 0.087094
              + 0.015306 u
              + 0.024829 v
              + 0.007638 u^2
              + 0.000399 v^2
```

- 拟合残差最大绝对值约 `0.00114`，二次模型对杂质拟合很好。
- 在最终点 `(0.508, 0.453)` 的预测杂质约 `0.08501`；最终点邻域 4 次实测为 `0.08393`、`0.08485`、`0.08564`、`0.08477`，与模型一致。
- 观测到的唯一超限点是初始数据 `(0.9, 0.9)` 的杂质 `0.12382`；说明约束主要在高 `x`、高 `y` 角点起作用，而收率最优区域并不贴着杂质边界。

## 4. 仪表口径与校准

- `instrument`：`original`；`metric`：`yield`。
- 收率单位：`%`；杂质单位：`fraction`（例如 `0.0848` 就是 `8.48%`，不是 `0.0848%`）。
- 输入坐标口径：归一化 `x`，范围 `[0,1]`。
- 两次 `calibrate`（`(0.5,0.5)` 与 `(0.508,0.452)`）均返回：
  - `instrument = "original"`
  - `metric = "yield"`
  - `offset = 0`
  - `unit = "normalized x"`
  - 成本各 2 单位
- 因校准偏移为 0，**未对原始读数做任何仪器修正**；所有原始读数按实验客户端返回值原样保存。
- quick 与 full 使用同一 `instrument = "original"`，但 quick 的 `noise_sd = 0.45`，明显高于 full 的 `0.18`。因此 quick 只用于早期侦察，**没有**混入全量响应面拟合；校准记录也没有作为测量值追加。

## 6. 验证与决策

1. 初始 9 点选出 additive 二次面，预测最优约 `(0.508,0.452)`。
2. 在该点做 full，得到 `95.406 %`、杂质 `0.08393`，与预测的 `95.22 %` 在 full 噪声范围内。
3. 在最优点的 `x±0.1`、`y±0.1` 四个方向补 full，拟合仍稳定选择 additive，最优基本不动；二次曲率与模型一致。
4. 在最终点邻域重复 full 三次，并在 `(0.508,0.453)` 追加一次最终全量验证；读数稳定，杂质始终在 `0.0839–0.0856` 之间。
5. 最终提交点取连续最优的近似值 `(0.508,0.453)`，并有该点的 full 原始读数作为直接验证证据。

## 7. 局限

- 响应面是**经验二次模型**，不能证明化学机理或因果关系；三次/更高阶项在当前数据下不显著，但不能完全排除。
- 预测值不是测量值；本结论的关键支撑是最终点及其邻域的真实 full 读数。
- 收率存在测量噪声。full 标称 `noise_sd = 0.18`；最终点附近 4 次读数样本标准差约 `0.094`，但样本量小，不能把 `95.43 %` 当作无误差真值。
- 最优面较平坦：`x,y` 在最优附近小幅变化对收率影响很小，参数的小数位不应被过度解读。
- 杂质约束在最优区域余量充足；但若把模型推到高 `x`、高 `y` 角点（如 `(0.9,0.9)`），会超过 `0.115`，因此不能做无边界的模型外推。
- 观测覆盖范围是 `[0.1,0.9] × [0.1,0.9]`；虽然变量定义域是 `[0,1]`，但边界附近的外推没有实验支撑。
- 校准只覆盖同一台 `original` 仪器和两个点，`offset = 0` 只能说明该口径下无加性偏移，不能排除乘性偏差或外部标准差异。
- quick 模式噪声较大，只用于侦察；若未来把 quick 并入拟合，需要单独建模其噪声/偏差，不能与 full 等权混合。
