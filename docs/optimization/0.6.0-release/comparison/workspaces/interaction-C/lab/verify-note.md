## 判定

- 复测 yield 95.343 与首次 95.286 一致（差 0.057 < 0.4）；
- 以两次均值计，(0.52,0.55) 与所有已测可行点的最大差异 0.132 < 1×noise_sd，且拟合面把该点排在最高；
- impurity 余量 0.0247 > 0.015，约束不紧。

因此 (0.52, 0.55) 通过 full 复测，可作为提交点；结论的精度受 full 的 0.18 noise_sd 与曲面平坦性限制，x、y 的有效分辨约 ±0.02–0.03。
