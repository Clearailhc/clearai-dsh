# 收率优化:参数、验证与局限

## 结论

提交参数 **x = 0.508,y = 0.452**。在该点用 full 模式实测两次:

| 次序 | 收率 | 杂质 | 仪表 | 文件 |
|---|---|---|---|---|
| 第 1 次 | 95.406 % | 0.08393 | original | `lab/full-optimum-1.json` |
| 第 2 次 | 95.517 % | 0.08445 | original | `lab/full-optimum-2.json` |

两次均值 **95.461 %**(单次噪声 sd 0.18,均值标准误约 0.13),杂质均值 **0.0842**,低于限值 0.115,余量约 0.031。两次读数差 0.111,小于 3σ=0.54。

## 依据

### 1. 响应曲面与参数

用 `method/response_surface.py` 对初始 9 条 full 读数拟合加性二次曲面,再并入 3 条新 full 读数重拟合(`lab/model-final.json`,共 12 条观测)。以缩放坐标 xs=2x−1、ys=2y−1 表示:

```
yield = 95.2569 + 0.2064·xs − 1.0231·ys − 6.6982·xs² − 5.4159·ys²
```

等价物理坐标:

```
yield(%) = 83.9594 + 27.2057·x + 19.6175·y − 26.7928·x² − 21.6636·y²
```

- 加性模型留一交叉验证 RMSE = **0.190**,与 full 读数噪声 sd 0.18 相当。
- 加入 x·y 交互项后 RMSE = 0.260,反而变差,交互项系数仅 0.058(缩放坐标),未达到 0.18 的噪声阈值 → 采用加性二次曲面。
- 连续最优解:x = 0.50770,y = 0.45277,预测收率 95.307 %;响应面脚本 21×21 网格推荐 (0.5,0.45),预测 95.305 %(95% 预测区间 94.92–95.69)。两者相差 <0.01 个百分点,提交点取连续最优。
- 曲率很平:单因素偏离 0.01 只损失约 0.004–0.005 个百分点,远小于读数噪声 0.18,故最优点附近无法再靠加测区分。

### 2. 杂质与约束

初始 9 点杂质可用加性二次式描述(残差 sd 约 0.0008):

```
impurity ≈ 0.05457 + 0.00214·x + 0.05009·y + 0.02838·x² − 0.00047·y²
```

在提交点预测杂质约 0.0856,两次 full 实测 0.08393 / 0.08445;限值 0.115 不紧。响应面脚本用默认杂质噪声 0.01 给出的预测上界 0.1061 仍低于 0.115(偏保守,按残差估计的真实噪声约 0.0008)。

### 3. 仪表口径

- 初始数据与全部新读数均为 **instrument = original**;`calibrate` 记录 **offset = 0**(成本 2,`lab/calibrate-1.json`)。
- 仪表一致性以 full 精度复核:在 (0.5,0.5) 重测得 95.105 %,与 initial 同点 95.184 % 差 −0.078(<3σ=0.54);杂质差 0.00017(`lab/full-center-1.json`)。
- full 模式读数噪声 sd = 0.18;quick 模式噪声 sd = 0.45(成本 1)。quick 只用于仪表粗查,未混入拟合(两者噪声口径不同)。
- 所有读数均为 `metric = yield`,收率单位 %,杂质为分数。

### 4. 预算台账

成本:quick 1 / full 3 / calibrate 2;总预算 30。`lab/budget.json` 记录:

| 项 | 成本 | 累计 |
|---|---|---|
| calibrate | 2 | 2 |
| quick (0.5,0.5) | 1 | 3 |
| full (0.5,0.5) 仪表复核 | 3 | 6 |
| full (0.508,0.452) 验证 | 3 | 9 |
| full (0.508,0.452) 复测 | 3 | 12 |

合计 **12**,余 **18**。未继续花费是有意的:最优点附近曲率导致 0.01 偏移的收率差 <0.005,远低于噪声 0.18,继续加测只能测到噪声,不能改进参数选择。

## 尚未确定的事项与局限

1. **模型形式**:只比较了加性/交互两种二次曲面;三层设计无法检验三次项或更复杂的局部结构。若真实曲面含未建模的三次项,最优位置可能轻微偏移,但当前两次 full 实测与模型预测(95.31)一致(实测 95.46,差 0.15<1σ),未见反证。
2. **适用域**:数据覆盖 x,y∈[0.1,0.9](观测包围盒);提交点 (0.508,0.452) 在盒内,属内插。对 [0,1] 边界附近的预测仅由二次模型外推,未实测,不能当作已验证结论。
3. **验证重复数**:提交点只有 2 次 full 重复,收率均值标准误约 0.13;真实期望收率仍可能有约 ±0.25(95%)的区间。杂质两次差 0.0005,远低于限值余量。
4. **仪表语义**:以上结论只在 instrument = original、offset = 0 时成立。若后续出现 replacement 仪表,必须重新 calibrate,不能沿用本次 offset,也不能把未校准的新读数与旧读数直接合并。
5. **预测≠测量**:响应面的 95.3 % 是模型预测;95.41/95.52 % 是两次实测。报告与提交以实测为准,模型用于选点。
6. **quick 读数**:仅 1 条,用于仪表粗查;其 0.45 的噪声口径不支持精细比较,未纳入拟合。
