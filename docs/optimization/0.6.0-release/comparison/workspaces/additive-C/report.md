# 收率优化报告：x, y ∈ [0,1]，杂质 ≤ 0.115

## 结论

推荐工艺点 **x = 0.500，y = 0.450**。该点已用 `full` 模式实测两次：

| 重复 | yield (%) | impurity (fraction) | 文件 |
|---|---:|---:|---|
| 1 | 95.5412 | 0.085162 | `lab/f-050-045.json` |
| 2 | 95.0957 | 0.084628 | `lab/f-050-045-rep.json` |
| 均值 | **95.318** | **0.084895** | — |

两次读数相差 0.446 个百分点，与 `full` 模式标称噪声 sd = 0.18 个百分点一致（差值 sd ≈ 0.255）。杂质均值比上限 0.115 低约 0.030，按拟合的杂质上界 0.106（95% 预测上限）仍有余量。

## 模型与参数

用 `method/response_surface.py`（0.5.2-rc.1）拟合。拟合调用是 `initial.json` 的 9 个 `full` 观测加 5 个 `--append` 的新 `full` 观测（共 14 个）；`lab/model-final.json` 的 `inputs` 字段记录了 `initial: initial.json` 与这 5 个 `lab/f-*.json` 路径及摘要。同一组合并后的输入快照另存为 `lab/input-final.json`，用于复算；输出为 `lab/model-final.json`。只用 `full` 数据，避免 `quick`（噪声 sd = 0.45）拉低精度。

模型比较（留一法 CV-RMSE，噪声 sd = 0.18）：

| 结构 | yield CV-RMSE | impurity CV-RMSE |
|---|---:|---:|
| 加性二次（无交互） | **0.1697** | 0.00125 |
| 含 x·y 交互 | 0.1914 | 0.00162 |

加性模型的验证误差不高于交互模型，且交互项没有超过噪声水平的改善，因此选加性二次面。令缩放坐标 `u = 2x−1`、`v = 2y−1`：

```
yield(%)      = 95.2363 + 0.05962u − 1.07975v − 6.73758u² − 5.79080v²
impurity(frac)= 0.08772 + 0.015372u + 0.024207v + 0.0083751u² − 0.0000646v²
```

由此得到连续最优 `u = 0.00442, v = −0.09323`，即 **x = 0.5022, y = 0.4534**，预测 yield = 95.287%，预测 impurity = 0.08553。该预测与已实测点 (0.500, 0.450) 的均值差异在噪声内，故提交实测点而非未测量的模型点。

## 实验设计与预算

总预算 30 单位，实际花费 30：

| 阶段 | 次数 | 单价 | 小计 |
|---|---:|---:|---:|
| `quick` 探索（中心 1 次 + 3×3 网格外围 8 次） | 9 | 1 | 9 |
| `calibrate`（花费 3、19、30 时各一次） | 3 | 2 | 6 |
| `full` 测量（0.5/0.4、0.5/0.6、0.5/0.45、0.55/0.45、0.5/0.45 复测） | 5 | 3 | 15 |
| **合计** | | | **30** |

原始读数全部保留在 `lab/`，未修改 `initial.json`。`quick` 数据用于定位峰值区域，最终拟合与提交只依赖 `full` 数据。

## 仪表口径

- 仪器：`original`，三次 `calibrate`（spent = 3、19、30，最后一次在提交点）均返回 `offset = 0`，未出现更换仪器或零点漂移的迹象，因此新旧读数可直接合并。
- 度量：`yield`，单位 `%`；`impurity` 为 fraction（不是百分数），上限 0.115。
- 噪声：`full` 模式标称 sd = 0.18 个百分点（`quick` = 0.45）；本次报告中的均值不确定性按单次 sd 0.18 估计，两次均值 sd ≈ 0.13。
- 预测值不是测量值：模型给出的 95.287% 是拟合预测，提交点的 95.318% 是实测均值。

## 局限

1. 二次响应面只在观测覆盖的 [0.1,0.9]² 盒内可信，不能外推到边界；按最终加性模型，角点 (0,0)≈83.7%、(1,1)≈81.7%，边中点约 88.4–90.5%，均明显低于内部峰值，但未做边界测量。
2. 峰值很平：x=0.50 的第 1 次读数 95.541 与 x=0.55 的 95.504 相差 0.037 个百分点；但 x=0.50 两次均值为 95.318，按均值则 x=0.55 高 0.186 个百分点。两种比较都落在 2 倍合并噪声（约 0.44–0.51）内。y 从 0.45 到 0.50 的模型差约 0.05 个百分点。x、y 的第三位小数没有实际意义，不要据此宣称精确最优。
3. 模型未包含未观测因素（如时间漂移、批次效应）；三次校准 offset 均为 0 只说明该时段内仪表一致，不构成因果结论。
4. 预算已用尽，未能对 (0.502, 0.453) 这一连续最优点做独立 `full` 复测；提交点 (0.500, 0.450) 是已复测点中均值最高者（单次最高读数也出现在该点：95.541），且与模型最优点相差 < 0.005。x=0.55 的单次 95.504 在噪声内与之相当。
5. 杂质余量约 0.030；若后续仪器或原料变化，应按新仪表重新校准后再判断 0.115 约束。
