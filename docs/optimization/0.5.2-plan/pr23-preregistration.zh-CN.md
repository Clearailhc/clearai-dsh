## 接受和停止

M1 负向回灌 ≥95%，M2 正确实际复用 ≥80%，范围误撤回和静默结案为 0，换装置不能误用旧补偿。t2–t4 的 C−A 均分 ≥0.5（满分4），并报告相对 t1 的变化。质量不劣时实验节省 ≥20%；C 错而自信数不超过 A，处理 token 不超过 A 的2.5倍。补充单题平均质量差不得小于−5标准化分。

正式分析按完整四题世界配对，不把题当作独立样本。质量和节省分别报告 97.5% 区间，固定 60,000 次配对 bootstrap、种子52023。点估计达线且区间下限支持正收益才“达到”；低于门槛为“未达到”，区间不足为“证据不足”。开发集用点估计决定是否扩大。两个收益不能补偿，禁止追加挑选有利世界。

缓存输入计入处理 token 并单列。缺 usage 为未知，下界保留；取消不记零成本。盲评费用另报。基础设施故障原配置最多重跑一次，原记录保留；模型失败不重跑。错误答案借旧裁决完成、失效跨会话消失、重复派发未阻塞、真值可读或模型变化立即停批次。正式开跑后候选冻结，任何修复开启新轮。
