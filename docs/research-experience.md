# Research events in 0.6.0

This version targets DSH 0.2.2-rc.1. ClearAI adds inline records of committed hypotheses, structural definitions, entity assertions, validation, independent reviews and outcomes through the official Conversation event registry and Chat node slot. Each record shows a short summary and at most three objects; details retain sources and evidence entry points. Tool success does not establish a research conclusion.

Type adjustments in ordinary conversation. Receipt is different from an applied change: the assistant reports effectiveness only after a revision commits through the existing research and goal tools. A reasonable default continues automatically; necessary missing information uses native questions. Native controls, connection indicators, subagent views, scrolling and notifications remain host-owned.

The separate `clearaiResearch` projection is a disposable UI cache, excluded from Session summaries and model prompts. It replays committed tool metadata and trusted kernel records, suppresses duplicate channels and preserves history. Refreshing it invokes no model. It cannot change facts, goals or task controls.

Inline object names are historical text, without navigation buttons, selection side effects, or fallback instructions. Research and Ontology are independent native tabs. Evidence links appear only when the host supplies the supported callback. Direct Chat-to-pane navigation remains outside the supported scope.

Whole-tool-view replacement is available, but no public composable native summary component was found. ClearAI preserves native tool presentation and raw details. It adds no suggested replies, alternate controls, polling service or scheduler.

Example replay is visibly marked and isolated from real knowledge. Models and automatic model-generated titles are not invoked. See the [acceptance record](optimization/0.6.0-release/README.md) for screenshots, retained failures and real-task, accessibility and performance scope. No speed or cost improvement is claimed.

The timeline and both panels share a restrained type and spacing system. Intent actions show a sending state until the native host confirms receipt; rejection remains visible, and stale-session actions are rejected. View registration is deferred past session teardown to avoid activating a released binding.

0.6.0 retains the 0.5.9 host capabilities. UI projection v4 labels refutation conditions and records evaluator handoff only after a child session is confirmed; pending audit ownership remains available for late results. Research columns use pane width, and locale subscriptions are disposed with the plugin.
