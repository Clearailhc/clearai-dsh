# 0.5.9 行内研究体验

当前是面向 DSH 0.2.2-rc.1 的未发布候选。ClearAI 通过官方对话事件注册表和 Chat 节点插槽，展示已提交的假设、结构定义、实体断言、验证、独立评估及阶段成果。默认只显示简短摘要和最多三个对象，详情保留来源及证据入口。工具成功不代表研究结论成立。

用户通过普通对话调整方向。收到要求不等于修改生效；只有既有研究与目标工具实际提交修订后，助手才能报告已生效。有合理默认路径时自动继续，必要信息使用原生提问。任务控制、连接状态、子任务、滚动与通知由宿主负责。

`clearaiResearch` 是可丢弃、可重放的 UI 缓存，排除于会话摘要之外，不进入模型提示。它读取已提交工具元数据和可信内核记录，对双通道去重，保留原位历史；刷新不调用模型，也不能修改事实、目标或任务控制。

行内对象名称只作为历史信息展示，不提供跳转按钮、不修改面板选择，也不显示手动跳转的补救提示。研究与本体是独立的原生页签；证据入口仅在宿主提供相应回调时展示。对话对象跨页签定位不属于 0.5.9 范围。

宿主提供整行工具替换，但未找到可组合的原生摘要组件；当前保留原生工具展示与原始详情。不新增建议回复、替代控制、轮询服务或调度器。

示例回放明确标注，与真实知识库隔离，不调用模型，自动标题模型也禁用。截图、失败记录及尚未完成的真实任务、可访问性与性能检查见[验收记录](optimization/0.5.9/README.md)。本次不声称速度或费用改善。

对话时间轴与研究、本体面板统一字重、留白及状态表达。意图操作先显示正在发送，宿主确认后才显示已发送；失败明确保留，过期会话操作被拦截。页签变更延迟到会话释放完成后执行，避免激活已经失效的绑定。
