# 发布前 recheck（逐组件）

面向「把这个插件发给别人用」的那一刻。**顺序即优先级**;每一格都写清
**判据 / 怎么验 / 通过线**,能机械化的就机械化(`tools/recheck.mjs`),剩下的人工项在文末。

## 怎么跑

```bash
# 机械面(单测 + 装机自检 + 打包 + 逐面字数预算)
node tools/recheck.mjs --log ~/.dsh/sessions/<桶>/<会话>/session.v3.jsonl.zstd

# 人工面(真浏览器):见文末「人工闸」
```

`--log` 给一场**有内容的真会话**(有目标/计划/步骤/证据/事实/技能那种)。没有就跳过字数预算那一节,
它会如实说"没量"。

## 人工闸(机器验不了的,发布前必须点一遍)

在**隔离家**里(别碰自己那份):

```bash
cp -a ~/.dsh /tmp/smoke-release && \
DSH_HOME=/tmp/smoke-release bash install.sh && \
cd /tmp && DSH_HOME=/tmp/smoke-release npx --no-install @deepseek-ai/dsh web --port 3092 --no-open
```

用浏览器逐条点:

1. **新建对话** → 发一句话 → 模型回话(证明插件没把 app 拖垮);
2. 中栏出现 **产物 / 事实** 两格;右栏「+」里有 **世界树 / 技能 · 记忆**;
3. 打开一场**有证据的**会话:命题展开 ⇒ 图上走过的那跳有证据 id;点证据的**出处**能开出预览;
4. 点「**在世界树里看这一步**」⇒ 世界树打开且**那一行被选中**;
5. 世界树详情点「**看这一步的证据**」⇒ 切回「事实」并展开对应命题;
6. 步骤详情的**产物**显示真实路径(不是 `undefined`),没查过的**不写「缺」**;
7. 多份计划的会话:页眉下拉能切到**旧世界树**,并标「已收尾 · 存档可看」;
8. 状态条:目标结案后**不再**出现「第 N 步」;
9. 工具行**没有**档位开关(§34 已删);立约时**一定**弹原生计划审阅,而且**只有人批准才落授权记号**(`confirmed_by='user'`;`'autonomy'` 这个来源已删除)。
   注意这条**不是**「人不批就推不动」:未授权只让自动续跑 `hold`(不自动往下跑),但 `AdvancePlan` 仍可执行,并在同一条变更里补写 `confirmed_by='progress'`。授权是记号与归属,不是闸门——见[已知缺口](known-gaps.zh-CN.md)。

任何一条不过 ⇒ 不发布,回到对应组件的用例先补一条回归。

## 已知的未验项(如实挂着,别假装)

- **双向跳转的"点在真浏览器里"那一下**:机制与数据都验过(单测 + 真投影渲染),
  但完整点通需要一场带计划与证据的真会话,目前只在 node 渲染层验过;
- **技能页描述仍偏长**(18 条 × 60 字 ≈ 1100 字):再压到只剩分类会让人认不出技能,
  停在"一句摘要"这个平衡点;
- **记忆条目多起来**时那一格还会长:需要时给"只看文件名"的默认;
- **客户端半也在宿主进程里缓存**:装完必须**重启 `dsh web`**,只刷新浏览器不够。
