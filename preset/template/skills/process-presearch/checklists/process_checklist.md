# 流程/系统预研 — 交付前自检清单

Checklist 是**发布闸门**，不是建议。任一关键项失败，必须补齐证据/口径，或明确标 `[信息缺失]` 并说明原因。

- [ ] 每个关键参数有来源标注 `[N]`
- [ ] 推断标 `[推断]`、信息缺口标 `[信息缺失]`
- [ ] 文末来源列表可点击，且 URL 均来自 `web_search` 实际返回（无编造）
- [ ] 2-3 个核心矛盾已识别（矛盾双方 + 量化影响 + 优化切入点）
- [ ] 5 类实体已追踪（输入要素/中间产物/消耗性资源/最终产出/支撑资源），每类含衡量方式+正常范围+下游影响
- [ ] 每个核心环节有决策点分析（两个方向的效果与副作用、当前倾向及原因）
- [ ] 3-5 个推演场景（输入→推演→决策），每个**量化**预期收益
- [ ] 微观精准-中观预判-宏观权衡三层框架完整
- [ ] 与传统做法（人工经验/固定规则）的对比表完整（视角/能力/决策/门槛）
- [ ] 关键参数给出数值范围，非“约/左右”
- [ ] 优化机会五要素明确（环节/问题/方法/收益/数据可获得性）
- [ ] 有对应数据时已生成图表，落盘 `lab/diagrams/{system_slug}_*.png`（禁止写入 `products/reports/`）
- [ ] 最终报告为单文件 `products/reports/{system_slug}_process_report.md`（禁止 `products/reports/{system_slug}/` 子目录）
- [ ] 报告内图表引用使用 `../../lab/diagrams/...`，未使用误导性的 `../diagrams/`
