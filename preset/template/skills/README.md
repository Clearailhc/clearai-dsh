# Skills 索引

本目录存放项目可用的 Skill。每个 Skill 一个子目录，入口为其中的 `SKILL.md`。
按需加载：先在此索引确认「该用哪个」，再打开对应 `SKILL.md` 获取完整方法。

## 方法学

- `exploration-loop` — 探索方法学骨架：假设 → 便宜验证 → 昂贵验证的证据升格循环；开始任何未知问题探索前先读。
- `scientific-brainstorming` — 开放式科研脑暴与发散创意；还没有具体观察、需要先扩大候选空间时用。
- `hypothesis-generation` — 把观察/文献线索收敛成可证伪的竞争假设与验证计划。
- `scientific-critical-thinking` — 评估证据可信度与偏倚；交叉验证检索结果、给来源分级时用。
- `what-if-oracle` — 多分支情景推演（最好/最可能/最坏/二阶效应）；方案变更或路线抉择前做压力测试。

## 调研与文献

- `domain-presearch` — 领域背景快速预研；进入新问题域时先摸清全貌与关键玩家/流派。
- `process-presearch` — 目标流程/系统的预研；需要先弄懂一条流程（实验、业务、自然过程）怎么运转时用。
- `literature-review` — 系统性文献综述（多库检索、主题综合、引用核验）。
- `paper-lookup` — 单篇论文定位与获取（DOI/标题/作者精确查找）。
- `citation-management` — 引用元数据核验与 BibTeX 管理。
- `process-understanding-extraction` — 从流程类资料中做可审计的理解抽取与制图（叙述定位、边界单元、拓扑骨架）。

## 数据与分析

- `exploratory-data-analysis` — 首次拿到数据文件时的结构/质量/分布初探与 EDA 报告。
- `data-qa-analysis` — 观测/实验数据的质量核查（来源清点、对齐、异常与可用性判定）。
- `data-analysis` — 已了解结构后的深度分析：变量关联、机理对照、领域知识提取。
- `statistical-analysis` — 假设的统计验证：选检验、查前提、出可审计结论。
- `chart-diagram-qa` — 图表落盘后的视觉验收与中文标签检查。

## 制品与应用

- `web-artifact` — 单文件自包含网页制品；把结果做成可双击打开、可标注回传的评审件。

## 元能力

- `skill-creator` — 创建或改进 Skill 本身；沉淀新方法为可复用 Skill 时用。
