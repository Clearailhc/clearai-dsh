# 任务六答案(电解液配方)

真实响应在 `surface.mjs`(`truth({c,a,b,Tf})` 给真实寿命 `life`,`linear` 是快测外推只看线性衰减得到的寿命)。

| 量 | 最优值 |
|---|---|
| 锂盐浓度 c | 1.2 M |
| 添加剂 A | 5 wt%(范围上限) |
| 添加剂 B | 2.1 wt%(约 0.4 × A) |
| 化成温度 Tf | 40 °C |
| 真实寿命 | 约 1700 圈 |

- **快测外推会骗人**:B 越多线性衰减越慢,外推寿命一路涨,外推最高的点是 A 5、B 3(外推约 2330 圈),真实寿命只有约 620 圈。B 多了会在第 100 圈之后出现拐点,快测看不到。
- **A×B 交互**:只有 B ≈ 0.4·A 时拐点才推后;偏离 0.5 wt% 拐点就提前到一千圈以内。一次只动一个量找不到。
- **早期征兆**:快测里的第 100 圈内阻增长,比例对时约 4%,偏离越远、B 越多越高(A 5、B 3 约 18%)。
- c 与 Tf 影响很小(各自 ±10% 以内),是干扰项。

计分(满分 5):
1. 推荐配方的真实寿命(按 `truth` 算):≥ 1550 圈 2 分;1200–1550 圈 1 分;< 1200 圈 0 分。
2. 指出快测外推在 B 多时高估寿命(有长测或内阻增长作证据):1 分。
3. 指出 B 要随 A 按比例搭配(约 0.4,或说清「B 只有在 A 足够时才有益」并给出数据):1 分。
4. 给出的预期寿命与推荐配方的真实寿命相差在 ±20% 以内:1 分。拿快测外推值当推荐配方的寿命、且该配方实际有拐点,记「错而自信」。
