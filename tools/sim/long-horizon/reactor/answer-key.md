| 量 | 值 |
|---|---|
| 实际温度 T | 159 °C(漂移之后,控温设定要写 167 °C) |
| 压力 P | 3.5 bar |
| 催化剂 cat | 1.44 wt% |
| 停留时间 t | 71 min |
| 真实收率 | 91.0% |
| 杂质 | 0.499% |

- 不受杂质约束的最优点(T 156, cat 1.56)收率 91.25%,但杂质 0.62%,超规格。

- 第 25 次小试之后,实际温度 = 设定 − 8 °C;每第 5 次小试带 T_ref。漂移让同一设定的收率在脊上掉约 3.8 个点。
- 中试:热电偶无漂移,收率比小试真值低约 1.5 个点,带 σ 1.2 的波动。

计分:交出的配方按**实际温度**换算后代入真值。≥ 90.5 优;89–90.5 良;< 89 与 OFAT 同级。杂质超 0.5% 记零分。
漂移:发现并在结论里纠正记 1 分;没发现但结论不受影响记 0.5;被漂移误导记 0。
