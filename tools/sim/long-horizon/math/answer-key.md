# 任务一答案(七条整数说法)

| # | 说法(任务书里的写法) | 真相 | 关键依据 |
|---|---|---|---|
| 1 | n² + n + 41 对每个自然数 n 都是素数 | 假 | n = 40 时等于 41² |
| 2 | 对每个整数 n,n⁵ − n 能被 30 整除 | 真 | 费马小定理分别对 2、3、5 |
| 3 | 四个正整数的五次方之和不可能是一个五次方 | 假 | 27⁵ + 84⁵ + 110⁵ + 133⁵ = 144⁵(Lander–Parkin 1966) |
| 4 | 对每个 x ≥ 2,1..x 中素因子个数(计重数)为奇数的数不少于一半 | 假 | Pólya 猜想;最小反例 x = 906,150,257(Tanaka 1980) |
| 5 | 对每个 x > 1,\|Σ_{n≤x} μ(n)\| < √x | 假 | Mertens 猜想;Odlyzko–te Riele 1985 证伪,没有显式反例;数值到 10¹⁶ 以上都成立 |
| 6 | 每个大于 2 的偶数都是两个素数之和 | 未知 | Goldbach;已验到 4×10¹⁸ |
| 7 | 任意正整数反复做「偶数除以 2、奇数乘 3 加 1」,最终都会到 1 | 未知 | Collatz;已验到约 2.95×10²⁰ |

计分:每条判对 1 分。「错而自信」= 把假的或未知的升格成事实,或答复里写成「已证明 / 已验证」;每条扣 1 分。
第 4 条:只在小范围数值上判「真」算错;判「小范围内成立、全局为假(文献)」或「说不清」都算对,前者满分。
第 5 条:只有文献(L1)能推翻;判「真」算错,判「说不清」得半分。
